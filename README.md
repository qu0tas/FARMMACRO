# Kaelix

**Маршруты, камера, Combat и Hunting в одном клиентском Fabric-моде.**

Kaelix — мод для Minecraft с инструментами для Hypixel SkyBlock: фермерскими маршрутами по точкам, ручным наведением, настройками камеры, рыбалкой и информационным HUD. Его основная идея — сократить повторяющиеся действия, сохранив понятное управление и возможность остановить работу.

Проект ориентирован на игру **в присутствии пользователя**, а не на полностью автономный AFK-режим. Ручные помощники и автоматические модули разделены: можно оставить только наведение и самому двигаться, атаковать и использовать предметы.

> **Важно:** автоматизация, Aim Assist и некоторые визуальные функции могут нарушать правила сервера. Kaelix не гарантирует отсутствие блокировок, не определяет администратора достоверно и не является официальным модом Hypixel. Используйте его только там, где это разрешено.

**Текущая версия:** `2.0.1` · **Minecraft:** `26.1.2` · **Fabric** · **Java 25**

## Возможности

| Раздел | Что доступно |
| --- | --- |
| **Фермы и маршруты** | Редактор точек в мире, конструктор фермерских схем, настройки переходов, сохранение, старт с участка пути, копирование и зеркалирование |
| **Запись действий** | Дополнительный способ создать и сохранить макрос записью действий |
| **Kaelix Motion** | Общие настройки камеры и навигации, движки Kaelix и Aether, скорость поворотов, сопровождение и параметры вариативности |
| **Ручной Aim** | Наведение на выбранного моба без автоматической ходьбы и атак, Hold/Toggle, Slayer- и Dungeon-каталоги |
| **Combat / Zealots** | Боевые профили, фильтры целей, сопровождение, отдельные опции Glacial Scythe, поиск Special и осмотр при отсутствии целей |
| **Hunting** | Ближайшая живая Mob-цель или каталог, группы локаций и отдельное упреждение |
| **AutoFish** | Подсечка своего поплавка, опциональный перезаброс и использование выбранного предмета после подходящих событий |
| **HUD** | Статус работы, инвентарь и модель игрока, навыки, питомец, наблюдаемая экономика, позиции, масштаб и видимость отдельных плашек |
| **Обзор и окно** | Freecam, Freelook, PiP, освобождение курсора и настройка работы уже запущенных задач при Alt+Tab |
| **Оформление** | Темы, прозрачность, цвета, визуализация маршрута и дополнительные косметические настройки |
| **Система** | Бинды в GUI, профили настроек, диагностические сведения и раздельные параметры остановок для фермы и автоматического Combat |

Открытие карточки модуля **не запускает** его. Разрешение функции, выбор настроек и фактический запуск — разные действия.

## Требования и установка

### Версии сборки 2.0.1

| Компонент | Версия |
| --- | --- |
| Minecraft Java Edition | **26.1.2** |
| Java | **25** |
| Fabric Loader | **0.19.5** |
| Fabric API | **0.155.3+26.1.2** |
| Kaelix | **2.0.1** |

Это **клиентский Fabric-мод**. Данная сборка не предназначена для Forge, NeoForge или других версий Minecraft. Устанавливать Kaelix на сервер не требуется.

### Установка JAR

1. Создайте в лаунчере профиль **Minecraft 26.1.2 + Fabric** и выберите Java 25.
2. Установите Fabric API для этой версии Minecraft.
3. Скачайте `kaelix-2.0.1.jar` из файлов релиза.
4. Поместите JAR в папку `mods` выбранного игрового профиля.
5. Удалите предыдущий Kaelix/FarmMacro JAR: одновременно должна оставаться только одна версия мода.
6. Запустите игру и откройте меню Kaelix.

Используйте обычный релизный JAR, а не архив исходников. Сторонние моды из раздела благодарностей отдельно устанавливать для описанных встроенных функций не нужно.

### Обновление

Перед обновлением сохраните копию настроек, маршрутов и записей. Имя проекта изменилось, но технические идентификаторы сохранены ради совместимости: `farmmacro`, `com.farmmacro` и файлы `config/farmmacro*` — это нормально.

Не удаляйте конфигурацию целиком без необходимости. В старых импортированных файлах отдельные параметры могли измениться или быть удалены; после обновления просмотрите выбранный режим и бинды.

## Первый запуск

1. Откройте меню — по умолчанию **Right Shift**.
2. В разделе **«Клавиши»** проверьте назначения и конфликты с другими модами.
3. Выберите задачу:
   - **«Фермы и маршруты»** — движение по точкам;
   - **«Combat / Hunting» → «Ручной Aim / Мобы»** — только наведение;
   - **автоматический Combat** — профиль с отдельно включаемыми дополнительными действиями;
   - **«Рыбалка / AutoFish»** — отдельный ручной запуск рыбалки.
4. Настройте **Kaelix Motion** и необходимые параметры выбранной задачи.
5. Расположите HUD через его редактор и отключите ненужные плашки.
6. Закройте меню и запустите выбранную функцию её клавишей или предусмотренной кнопкой.

Для первого знакомства удобнее включать **одну задачу за раз**. Не пытайтесь одновременно управлять камерой несколькими функциями.

### Выбор режимов и целей Combat

Клик по полю открывает **список с поиском** — не нужно по очереди перелистывать все имена.

- Ввод текста фильтрует названия и идентификаторы.
- Колёсико прокручивает список, не меняя настройку автоматически.
- Клик по строке применяет выбор.
- **↑ / ↓**, **Page Up / Page Down** — перемещение по списку, **Enter** — выбор.
- **Esc / «Назад»** — закрытие без изменения значения.

Так устроены выбор управления боем, ручной цели, режима клавиши и группы мобов в автоматическом Combat. Другие настройки интерфейса могут использовать свои элементы управления.

## Фермы и маршруты

**Маршруты по точкам — основной способ настройки фермерского движения.** Запись действий остаётся дополнительным вариантом.

### Редактор в мире

Точки задают путь и параметры переходов. Можно редактировать отдельные точки, их действия и настройки сохранённого маршрута, видеть линию пути в мире и возвращаться к сохранённым вариантам.

В режиме редактора доступны:

| Действие | Управление |
| --- | --- |
| Добавить точку / перетащить точку | ЛКМ / удержание ЛКМ |
| Вставить точку | Shift + ЛКМ |
| Удалить точку | ПКМ |
| Открыть параметры точки | Shift + ПКМ |
| Добавить к выделению | Alt + ЛКМ |
| Выделить все точки | Ctrl + A |
| Сдвинуть выделенные точки | Стрелки; Shift — мелкий шаг |
| Подготовить спуск на этаж ниже | Ctrl + D |
| Отменить изменение | Ctrl + Z |

### Конструктор схем

Есть схемы **S-shape, тростник, грибы, какао, A/D, W/S и Custom**. Настраиваются количество и длина проходов, расстояния переходов, клавиши движения, рабочий угол камеры и паузы смены ряда.

Конструктор создаёт маршрут под заданную геометрию. Он **не строит ферму и не распознаёт автоматически любой её дизайн**: размеры и ориентацию нужно согласовать со своим участком.

### Запуск с нужного места

- Обычный запуск требует находиться возле начала маршрута.
- **«Начать с места»** продолжает загруженный путь с ближайшего допустимого участка, учитывая направление и высоту.
- Функция не означает «дойти до пути из любой точки мира»: персонаж должен быть достаточно близко к маршруту.
- Допуск запуска и отдельный бинд настраиваются в меню.

### Копирование между этажами

В **«Копия и перенос маршрута»** можно создать отдельную копию, сдвинуть её по **X / Y / Z** и отзеркалить по X или Z. Это удобно для одинаковых этажей или соседних участков; исходный маршрут остаётся отдельным файлом.

Автовозврат — отдельная необязательная функция навигации, **выключенная по умолчанию**. Его наличие не заменяет корректный старт и подготовку маршрута.

## Камера и Kaelix Motion

**Kaelix Motion — общий раздел камеры и движения**, используемый задачами мода. Менять движок и основные параметры следует после остановки активной задачи.

### Движки

- **Kaelix** — собственные настройки поворота и трекинга; точный и человеческий режимы автоматического сопровождения.
- **Aether** — отдельный вариант камеры, кривых и пауз с собственными параметрами и пресетами.

Можно настраивать базовую скорость наведения, скорость захвата и сопровождения, вариативность скорости, параметры реакции, осмотр и повороты к Special. Для подходящих режимов доступны ограниченные перелёты, доводка и небольшой джиттер.

Фермерские схемы могут сохранять рабочий угол на проход и делать заминки на поворотах или переходах между этажами, не добавляя произвольных остановок посреди каждого прямого участка.

**Ручной Aim отличается от автоматического трекинга:** он использует общую базовую скорость наведения напрямую, без случайного джиттера и перелётов. Не все параметры хуманизации применяются к этому режиму. Запись действий также сохраняет собственные записанные углы.

Названия upstream-пресетов вроде `Safe` — названия настроек, **не обещание безопасности от блокировки**.

### Alt+Tab и PiP

Опция **«Работать при Alt+Tab / PiP»** позволяет продолжать уже запущенную ферму или автоматический Combat при уходе в другое окно. Она не запускает задачу самостоятельно и не отменяет остановки из-за мира, меню, реальной паузы или тревоги.

Для Combat в фоне нужен **Toggle**: отпускание клавиши в Hold завершает активацию. Ручной Aim по-прежнему требует активного игрового окна и захваченной мыши.

## Combat и ручной Aim

### Ручной режим

**Combat → Управление боем → Ручной Aim / Мобы**

Ты самостоятельно двигаешься, выбираешь предмет, атакуешь и стреляешь. Мод только наводит камеру на выбранную допустимую цель.

- **Hold** — наведение, пока удерживается клавиша.
- **Toggle** — включение и выключение повторным нажатием.
- Радиус и угол ограничивают первоначальный захват.
- Живая допустимая цель удерживается до её потери или отключения режима.
- Ручная смена предмета не требует заново включать разрешение Aim.

При меню, потере фокуса, смене мира, смерти или Freecam камера освобождается без панической тревоги; для продолжения требуется новая активация.

### Slayer

Есть выбор отдельных имён, ветки «босс / формы» и расширенного набора «босс + мини / формы».

| Ветка | Основные боссы каталога |
| --- | --- |
| Zombie | Revenant Horror |
| Spider | Tarantula Broodfather, Primordial Broodfather |
| Wolf | Sven Packmaster |
| Enderman | Voidgloom Seraph |
| Blaze | Inferno Demonlord |
| Vampire | Riftstalker Bloodfiend |

Для соответствующего ручного режима есть отдельная опция приоритета подтверждённых мешков с яйцами Tarantula. Прицеливание не выполняет выстрел за игрока.

### Данжи

Каталог содержит основные имена от **Bonzo, Scarf и The Professor** до **Maxor, Storm, Goldor и Necron**, а также мини-боссов: **Lost Adventurer, Frozen Adventurer, Angry Archaeologist, Shadow Assassin и King Midas**. Доступны отдельные имена и группы.

Это фильтры для наведения, а не полноценный решатель данжа. Мод не определяет владельца босса, настоящий Livid, текущую уязвимость или правильную тактику фазы. Watcher без живого доступного тела не захватывается; Thorn требует соответствующего фазе оружия.

### Glacial Scythe

В ручном Aim доступны:

- ограниченное упреждение по наблюдаемому движению цели;
- настраиваемая оценка скорости снаряда, задержка и предел прогноза;
- низкая точка наведения при подходящем пересечении тела и пола для возможного попадания и взрыва рядом.

Это геометрическая и скоростная оценка, **не гарантия двойного урона**. Резкое движение, серверные задержки и особенности коллизий могут привести к промаху.

### Автоматический Combat / Zealots

Автоматический режим имеет отдельные профили и параметры. В зависимости от включённых опций доступны:

- фильтры мобов и режим только Zealots;
- сопровождение целей, визуальное выделение и диагностика выбора;
- отдельная опция автовыстрела Glacial Scythe;
- переход к следующей цели после запроса выстрела;
- поиск и приоритет Special Zealot;
- осмотр с учётом недавних мест появления целей;
- отдельные параметры движения A/D и приседания;
- отдельные боевые остановки и уведомления.

Эти действия **не включаются автоматически при выборе ручного Aim**. Перед запуском проверьте, какой режим и профиль выбраны.

## Hunting

Hunting находится в том же списке ручных целей и не требует запуска автоматического Combat.

### Выбор целей

- **Ближайший моб — любое имя:** выбирает ближайшее допустимое живое Mob-тело в пределах радиуса, угла и видимости. Может выбрать и обычное животное, а не только Hunting-существо.
- **Каталог + водные:** использует известные Hunting-имена и реальные типы лягушек, головастиков, аксолотлей, рыб и кальмаров.
- **Группы Moonglade Marsh, Torrhus Canyon, Combat / Charm** и отдельные имена — более узкие фильтры.

При первом захвате Hunting отдаёт приоритет расстоянию, затем удерживает выбранную живую цель. Чтобы явно выбрать другую, отпустите Hold или выключите и снова включите Toggle.

### Упреждение

Отдельные настройки Hunting позволяют наводиться вперёд по движению цели. По умолчанию прогноз применяется с **луком, арбалетом и Glacial Scythe**; для нестандартных предметов есть переключатель применения с любым предметом.

Скорость снаряда, дополнительная задержка и предел упреждения регулируются. Значение **40 блоков/с — исходная оценка**, не универсальная серверная константа. Полная баллистика стрел, гравитация и сопротивление воды не моделируются.

Для лассо, сети и ближнего взаимодействия обычно полезнее отключить применение прогноза с другими предметами: тогда целью остаётся центр тела. **Выстрелы, лассо, сеть и REEL выполняет игрок.**

Обычные игроки, стойки с надписями и Display-декорации не являются Hunting-целями. Скрытые или декоративные модели без видимого подходящего Mob-тела могут не распознаться; полного покрытия всех серверных маскировок нет.

## Рыбалка

AutoFish — отдельный модуль с ручным запуском, а не часть боевого профиля.

1. Разрешите **AutoFish** и настройте подсечку/перезаброс.
2. Назначьте бинд либо используйте **«Запуск после закрытия меню»**.
3. Закройте меню, возьмите удочку и выполните **первый заброс вручную**.
4. Мод отслеживает свой поплавок и маркер поклёвки `!!!`, затем выполняет подсечку.
5. Если включён перезаброс, он выполняется после подтверждённого завершения предыдущего заброса.

Опциональная функция Fireveil / ПКМ предметом использует выбранный слот после подходящего наблюдаемого системного сообщения. Предмет и слот подготавливает игрок; наведения и движения эта функция не добавляет.

Таймаут, смена контекста или остановка не превращаются в бесконечный спам забросов. После остановки требуется новый ручной запуск. В интерфейсе часть рыболовных возможностей остаётся помеченной как экспериментальная.

## HUD и статистика

### Плашки

- Состояние текущей задачи, прогресс маршрута и навигация.
- Состояние Combat, текущая цель и дополнительные действия.
- **Инвентарь: 27 основных слотов + 9 слотов хотбара**, опциональная модель игрока.
- Навык, наблюдаемый XP, темп и оценка прогресса там, где есть достаточные данные.
- Информация о питомце и прогрессе уровня по доступным наблюдениям.
- Наблюдаемая экономика и её локальная история при включении соответствующих опций.

Статистика не является полным аудитом аккаунта. Пропущенные сообщения, неизвестные цены и устаревшие данные могут ограничивать результат. XP не выдумывается по количеству убийств, а XP питомца не подменяется XP навыка. Для обновления данных питомца может потребоваться открыть меню Pets.

### Редактор HUD

Открывается через GUI или **F8**. Плашки можно перемещать, масштабировать и настраивать отдельно. Для выбранного виджета есть режим **«Показ: всегда»** или **«Показ: по ситуации»**.

Опция **«HUD только по делу»** уменьшает количество плашек вне работы. Если нужен постоянный инвентарь или статистика, настройте видимость соответствующего виджета, а не запускайте ради этого макрос.

Доступны стиль Kaelix / Slate, прежний Legacy, параметры прозрачности и цветов. Показ инвентаря — только отображение: он не сортирует и не перемещает предметы.

### Обзор и оформление

Freecam и Freelook разделяют обзор с управлением персонажем; это разные функции. Дополнительно доступны PiP, Low Render, режим производительности, скрытие ника, темы и косметические элементы. Freecam не расширяет серверную дальность взаимодействия.

## Остановки и уведомления

У фермы и автоматического Combat **раздельные параметры событий и реакции на них**. В зависимости от настроек учитываются наблюдаемые изменения положения, мира, камеры, предмета и отдельные социальные события.

Возможны звуковой сигнал, экранное предупреждение и вывод окна вперёд. Причина остановки отображается в интерфейсе. Это не система достоверного определения staff: необычное событие может иметь другую причину.

- Автоматический Combat останавливается при боевой тревоге сразу.
- Для некоторых некритичных событий фермы предусмотрена короткая ограниченная задержка; критические события и ручная остановка не должны ждать её окончания.
- После тревоги нет обязательного подтверждения через B и нет автоматического продолжения или ответа в чат.
- **Изолированный ручной Aim не создаёт панику** из-за смены предмета, чата, телепорта или игроков рядом. Если одновременно работает автоматическая задача, её собственные проверки сохраняются.
- Проверка полного инвентаря как причина остановки удалена.

Не используйте случайность камеры или оповещения как обещание незаметности. Оставайтесь у компьютера и учитывайте правила сервера.

## Частые вопросы

### Мод не открывается или не загружается

Проверьте Minecraft/Fabric/API/Java по таблице выше, отсутствие второго JAR и конфликт бинда меню. Для сообщения об ошибке приложите подходящий фрагмент `latest.log` или crash report, предварительно удалив личные данные.

### Aim видит цель, но не наводится

Проверьте разрешение Aim, выбранное управление боем, Hold/Toggle, фильтр цели, радиус, угол захвата и видимость реального тела. Меню, Freecam, потеря фокуса или другая задача с управлением камерой могут блокировать ручное наведение. Одна надпись или ESP не доказывают наличие доступной цели для выстрела.

### Hunting выбирает не того моба

Режим «ближайший моб» намеренно не ограничен известными Hunting-именами и может выбрать обычное животное. Используйте конкретную группу или имя; для смены удерживаемой цели переактивируйте Aim.

### Почему упреждение ведёт слишком далеко или не хватает опережения?

Скорость снаряда — настраиваемая оценка. При чрезмерном опережении увеличьте её; при недостаточном уменьшите. Дополнительно ограничьте максимальное время прогноза. Разные предметы и серверные механики не обязаны иметь одинаковую скорость.

### Почему маршрут не начинает движение издалека?

Обычный запуск ожидает персонажа у начала пути. «Начать с места» работает рядом с допустимым участком уже загруженного маршрута, а не ведёт к нему из любой точки карты.

### Как оставить нужный HUD видимым постоянно?

Откройте F8, выберите виджет и переключите его на **«Показ: всегда»**. Проверьте, что сама плашка включена и не скрыта.

### Это гарантированно разрешено на Hypixel?

Нет. Присутствие игрока за ПК, обычные игровые действия и отсутствие специальных пакетов не означают разрешённость автоматизации. Проверяйте актуальные правила сервера; этот проект не даёт гарантий от блокировок.

## Сборка и разработка

Для работы с исходниками нужна **Java 25**. Gradle Wrapper находится в репозитории; устанавливать отдельный Gradle не обязательно. Первый запуск сборки может загружать зависимости.

### Linux / macOS

```bash
chmod +x gradlew
./gradlew --no-daemon assemble
```

### Windows

```powershell
.\gradlew.bat --no-daemon assemble
```

Готовый JAR находится в `build/libs/`. Для версии из этого README это `kaelix-2.0.1.jar`.

### Стек проекта

| Компонент разработки | Значение |
| --- | --- |
| Java toolchain | 25 |
| Gradle Wrapper | 9.7.1 |
| Fabric Loom | 1.18.3 |
| Имена Minecraft | Official Mojang names, non-remapping |
| Mod ID / пакет | `farmmacro` / `com.farmmacro` |

Основные точки входа:

```text
src/main/java/com/farmmacro/
├── combat/     # Aim, цели, боевые модули, Hunting
├── motion/     # Общая камера и управление движением
├── route/      # Точки, схемы, редактор и навигация
├── macro/      # Запись и воспроизведение
├── fishing/    # AutoFish
├── gui/        # Меню, настройки и поиск целей
├── hud/        # HUD и его редактор
├── config/     # Настройки и профили
└── panic/      # Остановки, наблюдения и уведомления
```

Перед изменениями прочитайте [AGENTS.md](AGENTS.md), [UPDATING.md](UPDATING.md) и актуальную запись в [CONTEXT.md](CONTEXT.md). В руководстве есть карта кода, ограничения, порядок переноса на новую версию Minecraft и требования к упаковке.

Полный source ZIP содержит `SOURCE-FILES.txt` и `REMOVED-FILES.txt`. При замене исходников обязательно удалите файлы из `REMOVED-FILES.txt`: загрузка через GitHub **Add files** сама не удаляет старые классы. Не публикуйте кеши, `.git`, локальные SDK и пользовательскую конфигурацию.

**Статус проверки 2.0.1:** релиз был скомпилирован и упакован без нового запуска Minecraft, тестов и `quickCheck` по запросу автора. Название релиза не является заявлением о полной игровой проверке. Эта редакция README меняет только документацию; поведение мода и JAR не изменены.
