# FarmMacro

Клиентский мод для Fabric: записывает твои действия на ферме и повторяет их, а при любом подозрительном событии делает **аварийный стоп** (паника): отпускает все клавиши, показывает красный экран и играет сирену.

**Minecraft 26.1.2 · Fabric Loader ≥ 0.19.5 · Fabric API 0.155.3+26.1.2 · Java 25 · мод v1.5.1**

## Клавиши (меняются в «Управление → FarmMacro»)

| Клавиша | Действие |
|---|---|
| R | начать / остановить запись (после остановки — окно сохранения) |
| P | запустить / остановить макрос |
| O | продолжить с места последней остановки |
| End | сбросить точку остановки |
| Delete | очистить буфер макроса |
| Правый Shift | меню мода |
| B | редактор маршрута по точкам (вкл/выкл) |
| H | запомнить текущий взгляд (yaw/pitch) в выбранный пресет камеры |
| K | плавно повернуться к выбранному пресету |
| J | следующий пресет камеры |

## Маршрут по точкам (альтернатива записи)

Маршрут можно не записывать, а построить в мире. Включи редактор (B). Пока он включён, ЛКМ и ПКМ ничего не ломают и не используют в мире:

- **ЛКМ по блоку**: точка в центре верхней грани (по пшенице и траве ставится на грядку под ней). ЛКМ по точке выбирает её, если зажать и вести прицел, точка двигается.
- **Shift+ЛКМ**: вставить точку в ближайший отрезок. **ПКМ по точке**: удалить. **Shift+ПКМ по точке**: параметры.
- **Ctrl+ЛКМ по двум углам грядки**: «змейка» по рядам (шаг, направление и действия на рядах и переходах настраиваются). Это главный способ для ферм.
- **Ctrl+Z**: отменить последнее действие.

Параметры точки действуют на отрезке до следующей точки: ничего / держать ЛКМ / держать ПКМ, присесть, спринт, прыжок в начале отрезка, слот хотбара, пауза в точке (в тиках), свой pitch (иначе pitch маршрута).

Автоход (P, если в «Макросы» выбрано «Маршрут по точкам» или маршрут только что загружен или изменён) поворачивает камеру к следующей точке плавно, с ограничением скорости и без случайности. Он идёт вперёд и считает точку пройденной в радиусе 0.3 блока. Препятствия не обходит: если упёрся, срабатывает паника «Застрял». Работает всё то же, что для записи: все детекторы паники, цикл, лимиты кругов и времени, стоп при полном инвентаре, отсчёт, проверка точки старта, HUD («точка N/M») и O (продолжить с места остановки).

## Пресеты камеры

У каждой культуры свои yaw и pitch. Встань как нужно и нажми H, потом K вернёт этот взгляд из любого положения, а J переключит на следующий пресет. Поворот плавный, с постоянной скоростью и торможением в конце (скорость настраивается, можно сделать мгновенным), без случайных движений. Пресеты (до 16), подпись культуры, точные значения и «Yaw ровно по оси» находятся во вкладке «Запуск» → «Камера». Пока макрос сам управляет камерой (автоход или «Повторять камеру»), пресеты не применяются.

## Меню

Своё оформление, без текстур Minecraft. Настройки сохраняются сразу.

- **Детекторы**: поворот камеры, смена слота, урон, открытое окно, телепорт или поворот от сервера, блок вплотную к игроку, эффекты, застревание, сход с маршрута. У каждого свой переключатель и пороги.
- **Реакция**: звук паники (4 встроенные сирены, свои `.ogg`/`.wav` или звуки Minecraft), **«Безопасный звук»** (включён по умолчанию: всё играет только через звуковой движок игры), режим «мимо громкости игры» (работает, когда «Безопасный звук» выключен), громкость, тон, число повторов, красный экран, кнопка «Проверить панику». Свои файлы звучат только при выключенном «Безопасном звуке», иначе вместо них встроенная сирена.
- **Запуск**: цикл и число кругов, лимит времени, стоп при полном инвентаре, сигнал по окончании, обратный отсчёт, точка старта, повтор камеры, настройки HUD (панель статуса, навигатор, стрелка у прицела). Навигатор не пропадает у цели: показывает «✔ На месте».
- **Визуал**: **маршрут макроса** в мире: светящаяся лента по записи или по точкам маршрута (цвет, непрозрачность и «свечение» настраиваются; номера точек над ними) (впереди ярко, пройдено серым, запись — красным), зелёный старт, красная точка остановки, текущая позиция, стрелки направления, участки ЛКМ/ПКМ и точки прыжка/приседания. Настройки: когда показывать, сквозь стены (нет / слегка / ярко), толщина, радиус, стрелки и их шаг, «от точки запуска» (если запускаешь не с места записи). Рисуется только рядом с игроком и в том измерении, где макрос записан или загружен. «China Hat» — полупрозрачная шляпа-конус над головой (видишь только ты). Пресеты «Фиолет → оранж» и «Голубой», стиль (градиент / однотонный / перелив), два цвета, прозрачность, радиус полей, высота, смещение, скорость, количество сегментов, показ от первого лица (по умолчанию нет, в F5 видно всегда), шляпы на всех игроках (по умолчанию нет).
- **Макросы**: что играет клавиша запуска (запись или маршрут), текущий буфер (запустить, сохранить, очистить), список сохранённых (▶ загрузить и запустить, загрузить, удалить с подтверждением). Раздел **«Маршруты»**: текущий маршрут (редактор, запуск, сохранение, очистка), pitch маршрута, скорость поворота автохода, радиус точки, настройки «змейки», сохранённые маршруты с теми же действиями.

Управление: кликни по числу или списку (появится рамка), и колёсико будет менять значение (с Shift шаг крупнее). Без клика колёсико просто прокручивает меню, поэтому пороги не собьются случайно. Tab и Shift+Tab переключают вкладки, колёсико над боковой панелью тоже.

## Файлы

- `config/farmmacro.json`: настройки.
- `config/farmmacro_macros/*.json`: сохранённые макросы.
- `config/farmmacro_routes/*.json`: маршруты по точкам (версия, имя, мир, измерение, pitch, точки с параметрами).
- `config/farmmacro/sounds/`: свои звуки паники (`.ogg` или `.wav`). Старый `config/farmmacro/panic.wav` переносится сюда сам.

## Сборка

```
./gradlew build        # JDK 25; готовый jar в build/libs/
./gradlew soundStress  # проверка декодера звуков вне игры (1000 декодов каждого звука)
./gradlew routeStress  # упрощение маршрута на 70 000 кадров, «змейка», симуляция автохода
```

Встроенные звуки генерирует `tools/gen_panic_sounds.py` (нужны numpy и ffmpeg с libvorbis).

## Границы

Паника только останавливает макрос и подаёт сигнал. Автоход и плавный поворот камеры детерминированные: никакой случайности. Мод не имитирует «человеческое» поведение, не обходит античиты и проверки администраторов и не продолжает работу сам после паники. Используй на своём мире или сервере.
