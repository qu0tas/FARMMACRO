# Farm Macro

Клиентский Fabric-мод для Minecraft: записывает действия игрока на ферме и повторяет их,
с аварийной остановкой («паникой»), если во время макроса происходит что-то неожиданное.
Сделан для видео; используется в одиночной игре или на своём сервере.

> **Для ИИ-агентов и тех, кто продолжает работу:** сначала прочитай [`CONTEXT.md`](CONTEXT.md) —
> там полное состояние проекта, история, что сделано и что осталось, и правила ведения проекта.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/) для Minecraft 26.1.2.
2. Положи в папку `mods` [Fabric API](https://modrinth.com/mod/fabric-api) для 26.1.2 и `farmmacro-1.1.0.jar`.
3. Запусти игру. Клавиши мода — в «Настройки → Управление», категория **FarmMacro**.

## Как пользоваться

| Клавиша (по умолчанию) | Действие |
|---|---|
| **R** | Начать / остановить запись. После остановки открывается окно сохранения макроса |
| **P** | Запустить / остановить воспроизведение |
| **Delete** | Очистить текущую запись |
| **Right Shift** | Открыть меню мода |
| **O** | Продолжить макрос с места последней остановки |
| **End** | Сбросить сохранённое место остановки |

Записывается каждый тик: позиция, поворот камеры, клавиши движения, прыжок, присед, бег,
ЛКМ/ПКМ и слот хотбара. При воспроизведении мод нажимает те клавиши, которые назначены
у игрока в управлении.

### Паника (аварийный стоп)

Во время воспроизведения мод следит за событиями, которые макрос сам не вызывает:

- поворот камеры (А), телепорт (Б), твёрдый блок появился перед лицом (В);
- смена слота снаружи (Г), открылось чужое окно (Д), получен урон;
- сервер принудительно повернул камеру (Ж), добавился/снялся эффект зелья (З);
- игрок застрял: макрос «идёт», а позиция не меняется и впереди блок.

При срабатывании макрос **сразу останавливается**, все клавиши отпускаются, показывается
красный экран и играет звук тревоги. Детекторы, пороги, звук и длительность красного экрана
настраиваются в меню (вкладки «Паника» и «Реакция»).

### HUD

- Статистика сессии: время и число запусков (выключается в меню).
- Метка сохранённого места остановки: стрелка и расстояние.

## Файлы мода в папке игры

| Путь | Что там |
|---|---|
| `config/farmmacro.json` | Настройки мода |
| `config/farmmacro_macros/*.json` | Сохранённые макросы |
| `config/farmmacro/panic.wav` | (необязательно) свой звук паники для режима «системный звук» |

## Сборка из исходников

Нужна **JDK 25**.

```bash
./gradlew build        # готовый мод: build/libs/farmmacro-<версия>.jar
./gradlew runClient    # запустить игру с модом для проверки
```

Путь к JDK **не** пишется в `gradle.properties` проекта (ломает сборку на GitHub).
Если Gradle не находит Java 25, укажи `org.gradle.java.home` в `%USERPROFILE%\.gradle\gradle.properties`.

## Структура кода

```
src/main/java/com/farmmacro/
├── FarmMacroMod.java          точка входа: клавиши, тик-цикл
├── config/ModConfig.java      настройки (farmmacro.json)
├── gui/                       меню мода и окно сохранения макроса
├── macro/                     запись/воспроизведение, хранение, HUD
├── mixin/                     перехват событий для паники
└── panic/                     детектор паники и красный экран
```

Подробное описание каждого класса — в [`CONTEXT.md`](CONTEXT.md).
