# FarmMacro

Клиентский мод для Fabric: записывает твои действия на ферме и повторяет их, а при любом подозрительном событии делает **аварийный стоп** (паника): отпускает все клавиши, показывает красный экран и играет сирену.

**Minecraft 26.1.2 · Fabric Loader ≥ 0.19.5 · Fabric API 0.155.3+26.1.2 · Java 25 · мод v1.8.0**

## Клавиши (меняются в «Управление → FarmMacro»)

| Клавиша | Действие |
|---|---|
| R | начать / остановить запись (после остановки — окно сохранения) |
| P | запустить / остановить макрос |
| O | продолжить с места последней остановки |
| End | стоп и сброс: остановить, сбросить точку остановки, указатели (маяк, навигатор, подсветку) и зажим мыши |
| Delete | очистить буфер макроса |
| Правый Shift | меню мода |
| B | редактор маршрута по точкам (вкл/выкл) |
| H | запомнить текущий взгляд (yaw/pitch) в выбранный пресет камеры |
| K | применить выбранный пресет камеры (плавно или мгновенно) |
| J | следующий пресет камеры |
| L | зажим ЛКМ вкл/выкл (держать ЛКМ без пальца на кнопке) |

## Маршрут по точкам (альтернатива записи)

Маршрут можно не записывать, а построить в мире. Включи редактор (B). Пока он включён, ЛКМ и ПКМ ничего не ломают и не используют в мире:

- **ЛКМ по блоку**: точка в центре верхней грани (по пшенице и траве ставится на грядку под ней). ЛКМ по точке выбирает её, если зажать и вести прицел, точка двигается.
- **Shift+ЛКМ**: вставить точку в ближайший отрезок. **ПКМ по точке**: удалить. **Shift+ПКМ по точке**: параметры.
- **Ctrl+ЛКМ по двум углам грядки**: «змейка» по рядам (шаг, направление и действия на рядах и переходах настраиваются). Это главный способ для ферм.
- **Ctrl+Z**: отменить последнее действие.

- **Смещение внутри блока**: выбери точку (ЛКМ) и двигай стрелками: ↑/↓ — вперёд/назад, ←/→ — влево/вправо относительно взгляда, шаг 0.05 блока (с Shift — 0.01, оба настраиваются). Точка остаётся в своём блоке (от −0.5 до +0.5 от центра). **Alt+ЛКМ** — выделить ещё точки, **Ctrl+A** — все (так можно сдвинуть весь маршрут или всю «змейку» чуть вперёд). В окне точки (Shift+ПКМ) смещение X/Z вводится числом, есть «В центр», «Выделенным», «Всему маршруту». У «змейки» есть «Смещение рядов X/Z» при построении. Ctrl+Z отменяет сдвиг (серия нажатий подряд — одним шагом), смещение сохраняется в файл маршрута.

Параметры точки действуют на отрезке до следующей точки: ничего / держать ЛКМ / держать ПКМ, «Зажим мыши» (для режима «по точкам», см. ниже), присесть, спринт, прыжок в начале отрезка, слот хотбара, пауза в точке (в тиках).

Автоход (P, если в «Макросы» выбрано «Маршрут по точкам» или маршрут только что загружен или изменён) **не поворачивает камеру**: yaw и pitch весь проход остаются такими, какие поставил ты (удобно — пресетом камеры, K). К точке он идёт клавишами W/A/S/D относительно текущего yaw: направление раскладывается по осям камеры (8 направлений). Если yaw смотрит ровно вдоль рядов «змейки», ряды проходятся чистыми W/S, переходы — A/D. Спринт работает только вместе с W. Точка считается пройденной в радиусе 0.3 блока. Препятствия не обходит: если упёрся, срабатывает паника «Застрял». Работает всё то же, что для записи: все детекторы паники, цикл, лимиты кругов и времени, стоп при полном инвентаре, отсчёт, проверка точки старта, HUD («точка N/M») и O (продолжить с места остановки).

## Камера (yaw/pitch)

Отдельная вкладка меню **«Камера»**, не привязанная к макросам. Пресет — это имя, yaw, pitch и подпись культуры (до 16 пресетов).

- Значения вводятся числом вручную: кликни по полю, впиши, например, `90.0` или `12.345` (точка или запятая), Enter — принять, Esc — отменить. Yaw как в F3 (−180…180, 270 станет −90), pitch от −90 (вверх) до 90 (вниз). Неверное число подсвечивается красным.
- «Взять текущие» записывает в пресет, куда ты сейчас смотришь. «Yaw ровно по оси» округляет до 45°.
- **Применить пресет**: K (или кнопка «Применить» / ◎ в списке), J — следующий пресет, H — записать текущий взгляд в выбранный. Работает в любой момент, в том числе во время автохода. Не работает только пока запись играет с «Повторять камеру».
- Плавный поворот есть только здесь, при применении пресета: постоянная скорость (настраивается, °/с) с торможением в конце, без случайности. Можно выключить, тогда поворот мгновенный. Свой поворот не вызывает панику «Камера повернулась», а движение мыши поверх него вызывает.

## Настройки макроса (⚙)

У каждого макроса и маршрута свои настройки. Кнопка **⚙** есть у карточки текущего макроса и текущего маршрута (справа вверху) и у каждого сохранённого (левее ▶). Откроется окно «Настройки макроса»:

- для **сохранённого** макроса или маршрута файл переписывается при закрытии окна (кадры и точки не трогаются). Если он сейчас загружен, новые настройки сразу действуют;
- для **текущего макроса** (загруженного) — запись в файл при закрытии окна; для новой записи настройки сохранятся вместе с ней;
- для **текущего маршрута** правки помечают его «изменён» (Ctrl+Z в редакторе отменяет всё окно разом), в файл — кнопкой «Сохранить».

Править можно, пока ничего не играет и не пишется.

### Камера

Сам по себе ни макрос, ни автоход камеру не крутят. Можно выбрать:

- **Нет**: камера остаётся как есть.
- **Один на всё**: при старте (и в начале каждого круга) камера мгновенно встаёт в выбранный пресет.
- **По точкам / по кадрам**: «с точки N — пресет X» (для записи — с кадра N). При старте ставится пресет, действующий на этом месте, дальше камера мгновенно меняется, когда дошли до N.

После установки yaw/pitch больше не меняются. Плавности здесь нет: поворот мгновенный и детерминированный, детектор паники о нём знает. Хранится копия yaw/pitch, поэтому, если удалить пресет, сработают сохранённые значения. Пока у записи выбран пресет, «Повторять камеру» для неё не действует. Если yaw пресета не совпадает с yaw, с которым сделана запись, окно предупредит: клавиши из записи поведут в другую сторону.

### Зажим мыши

Держать кнопку мыши во время воспроизведения — вместе с тем, что жмёт сама запись или точка маршрута:

- **Кнопка**: нет / ЛКМ / ПКМ.
- **Когда**: весь проход, или **по участкам** (запись: «с тика … по тик …», номера кадров включительно, участков можно несколько), или **по точкам** (маршрут: галочка «Зажим мыши» в параметрах точки, Shift+ПКМ в редакторе; зажато на отрезке от неё до следующей).
- **Задержка старта**: сколько тиков после начала воспроизведения (после отсчёта) не зажимать, вводится числом (20 тиков = 1 с).

**Ручной зажим ЛКМ** — клавиша L: работает и без макроса, в HUD плашка «ЗАЖИМ ЛКМ». Не включается, пока открыт редактор маршрута.

Зажим всегда отпускается: стоп, паника, End, открытие любого окна (ручной зажим при этом выключается), выход из мира, открытие редактора. Пока открыто окно, ничего не зажимается.

## Меню

Своё оформление, без текстур Minecraft. Настройки сохраняются сразу.

- **Детекторы**: поворот камеры, смена слота, урон, открытое окно, телепорт или поворот от сервера, блок вплотную к игроку, эффекты, застревание, сход с маршрута. У каждого свой переключатель и пороги.
- **Реакция**: звук паники (4 встроенные сирены, свои `.ogg`/`.wav` или звуки Minecraft), **«Безопасный звук»** (включён по умолчанию: всё играет только через звуковой движок игры), режим «мимо громкости игры» (работает, когда «Безопасный звук» выключен), громкость, тон, число повторов, красный экран, кнопка «Проверить панику». Свои файлы звучат только при выключенном «Безопасном звуке», иначе вместо них встроенная сирена.
- **Запуск**: цикл и число кругов, лимит времени, стоп при полном инвентаре, сигнал по окончании, обратный отсчёт, точка старта, повтор камеры, настройки HUD (панель статуса, навигатор, стрелка у прицела). Навигатор не пропадает у цели: показывает «✔ На месте».
- **Визуал**: цвета выбираются из палитры, в которой есть чёрный и тёмно-серый: лента, точки, номера, маяки старта и остановки, стрелки, превью «змейки», шляпа; в «Запуск → HUD» — цвет и фон HUD. **Маршрут макроса** в мире: светящаяся лента по записи или по точкам маршрута (цвет, непрозрачность и «свечение» настраиваются; номера точек над ними) (впереди ярко, пройдено серым, запись — красным), зелёный старт, красная точка остановки, текущая позиция, стрелки направления, участки ЛКМ/ПКМ и точки прыжка/приседания. Настройки: когда показывать, сквозь стены (нет / слегка / ярко), толщина, радиус, стрелки и их шаг, «от точки запуска» (если запускаешь не с места записи). Рисуется только рядом с игроком и в том измерении, где макрос записан или загружен. «China Hat» — полупрозрачная шляпа-конус над головой (видишь только ты). Пресеты «Фиолет → оранж» и «Голубой», стиль (градиент / однотонный / перелив), два цвета, прозрачность, радиус полей, высота, смещение, скорость, количество сегментов, показ от первого лица (по умолчанию нет, в F5 видно всегда), шляпы на всех игроках (по умолчанию нет).
- **Макросы**: что играет клавиша запуска (запись или маршрут), текущий буфер (запустить, сохранить, очистить, ⚙ настройки), список сохранённых (⚙ настройки, ▶ загрузить и запустить, загрузить, удалить с подтверждением). Раздел **«Маршруты»**: текущий маршрут (редактор, запуск, сохранение, очистка, ⚙), радиус точки, настройки «змейки», сохранённые маршруты с теми же действиями.

- **Камера**: пресеты yaw/pitch (см. выше).

Любое число можно ввести вручную: кликни по значению, впиши (точка или запятая), Enter — принять, Esc — отменить; при ошибке под подписью появится причина («не число», «не меньше …», «нужно целое число»). Пределы широкие, например порог поворота можно поставить 0.001°. После клика по числу или списку (появится рамка) колёсико меняет значение (с Shift шаг крупнее), −/+ — тоже. Без клика колёсико просто прокручивает меню, поэтому пороги не собьются случайно. Tab и Shift+Tab переключают вкладки, колёсико над боковой панелью тоже.

## Файлы

- `config/farmmacro.json`: настройки.
- `config/farmmacro_macros/*.json`: сохранённые макросы (версия 4: настройки макроса в `settings` — камера и зажим мыши; версии 1–3 читаются, привязка камеры из версии 3 переносится сама).
- `config/farmmacro_routes/*.json`: маршруты по точкам (версия 4: имя, мир, измерение, точки с параметрами и смещением в блоке `ox`/`oz`, `settings`; версии 1–3 читаются (смещение 0), привязка камеры из версии 2 переносится сама, старое поле pitch игнорируется).
- `config/farmmacro/sounds/`: свои звуки паники (`.ogg` или `.wav`). Старый `config/farmmacro/panic.wav` переносится сюда сам.

## Сборка

```
./gradlew build        # JDK 25; готовый jar в build/libs/
./gradlew soundStress  # проверка декодера звуков вне игры (1000 декодов каждого звука)
./gradlew routeStress  # упрощение маршрута на 70 000 кадров, «змейка», симуляция автохода
```

Встроенные звуки генерирует `tools/gen_panic_sounds.py` (нужны numpy и ffmpeg с libvorbis).
