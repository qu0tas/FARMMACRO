# FarmMacro

Клиентский мод для Fabric: записывает твои действия на ферме и повторяет их, а при любом подозрительном событии делает **аварийный стоп** (паника): отпускает все клавиши, показывает красный экран и играет сирену.

**Minecraft 26.1.2 · Fabric Loader ≥ 0.19.5 · Fabric API 0.155.3+26.1.2 · Java 25 · мод v1.10.0**

Полное описание всех настроек — [docs/SETTINGS.md](docs/SETTINGS.md). Промт для нейросети, чтобы подобрать идеальный конфиг, — [docs/AI_CONFIG_PROMPT.md](docs/AI_CONFIG_PROMPT.md).

## Клавиши (меняются в «Управление → FarmMacro»)

| Клавиша | Действие |
|---|---|
| R | начать / остановить запись (после остановки — окно сохранения) |
| P | запустить / остановить макрос |
| O | продолжить с места последней остановки |
| End | стоп и сброс: остановить, сбросить точку остановки, указатели (маяк, навигатор, подсветку) и зажим мыши |
| Delete | очистить буфер макроса |
| Правый Shift | меню мода |
| B | редактор маршрута по точкам (вкл/выкл) |
| H | запомнить текущий взгляд (yaw/pitch) в выбранный пресет камеры |
| K | применить выбранный пресет камеры (плавно или мгновенно) |
| J | следующий пресет камеры |
| L | зажим ЛКМ вкл/выкл (держать ЛКМ без пальца на кнопке) |
| M | блокировка мыши вкл/выкл (мышь не крутит камеру; при панике снимается сама) |

## Маршрут по точкам (альтернатива записи)

Маршрут можно не записывать, а построить в мире. Включи редактор (B). Пока он включён, ЛКМ и ПКМ ничего не ломают и не используют в мире:

- **ЛКМ по блоку**: точка в центре верхней грани (по пшенице и траве ставится на грядку под ней). ЛКМ по точке выбирает её, если зажать и вести прицел, точка двигается.
- **Shift+ЛКМ**: вставить точку в ближайший отрезок. **ПКМ по точке**: удалить. **Shift+ПКМ по точке**: параметры.
- **Ctrl+ЛКМ по двум углам грядки**: «змейка» по рядам (шаг, направление и действия на рядах и переходах настраиваются). Это главный способ для ферм.
- **Ctrl+Shift+ЛКМ по двум углам фермы**: **авто-маршрут** (v1.11) — мод сам сканирует блоки, находит урожай, воду, проходы, лестницы и опасные блоки, определяет тип фермы (линейный / зигзаг / спираль / сложный) и где идти (пшеница/морковь/картошка/наросты — по воде ниже грядок, арбузы/тыквы/тростник/цветы — на уровне урожая с советом yaw 45°), ось и шаг рядов, этажи, и строит маршрут: ряды «змейкой», переходы и обходы дыр по кратчайшему пути (A*), спуски между этажами, по желанию — возврат к старту. В чат — что найдено и предупреждения. То же — кнопкой «Маршруты → Авто-маршрут → Выделить область» (тогда хватит обычного ЛКМ по углам). Ctrl+Z отменяет. Проверь превью перед запуском.
- **Ctrl+D**: «Спуск» у выбранной точки (см. «Этажи и спуск» ниже). Повторно — снять.
- **Ctrl+Z**: отменить последнее действие.

- **Смещение внутри блока**: выбери точку (ЛКМ) и двигай стрелками: ↑/↓ — вперёд/назад, ←/→ — влево/вправо относительно взгляда, шаг 0.05 блока (с Shift — 0.01, оба настраиваются). Точка остаётся в своём блоке (от −0.5 до +0.5 от центра). **Alt+ЛКМ** — выделить ещё точки, **Ctrl+A** — все (так можно сдвинуть весь маршрут или всю «змейку» чуть вперёд). В окне точки (Shift+ПКМ) смещение X/Z вводится числом, есть «В центр», «Выделенным», «Всему маршруту». У «змейки» есть «Смещение рядов X/Z» при построении. Ctrl+Z отменяет сдвиг (серия нажатий подряд — одним шагом), смещение сохраняется в файл маршрута.

Параметры точки действуют на отрезке до следующей точки: ничего / держать ЛКМ / держать ПКМ, «Зажим мыши» (для режима «по точкам», см. ниже), присесть, спринт, прыжок в начале отрезка, слот хотбара, пауза в точке (в тиках).

### Этажи и спуск

Мод видит блоки: в редакторе отрезок, который идёт сквозь блоки, через дыру в полу или на этаж ниже без спуска, подсвечивается **красным**, а в HUD редактора пишется, что не так («Отрезок 3→4: препятствие»).

**Спуск** — точка, из которой падаешь на этаж ниже. Автоход доходит до неё, шагает дальше по направлению спуска до края, падает, после приземления ждёт «Паузу после приземления» и идёт к следующей точке уже с места приземления. Лента рисуется по верхнему этажу до края, вниз и дальше — не сквозь блоки.

- **Ctrl+D** по выбранной точке: если следующая точка ниже, а на линии между ними есть край — мод сам вставит точку-спуск на последнем блоке перед краем. Если этажи друг под другом (края на линии нет) — выбранная точка сама станет спуском «по ходу» (дальше в ту же сторону, куда шёл).
- В окне точки (Shift+ПКМ) — раздел «Спуск на этаж ниже»: вкл/выкл, направление (по ходу / ±X / ±Z), пауза после приземления, «в полёте держать клавишу» (выкл — отпустить сразу после края и падать почти вертикально). Там же видно, на сколько блоков падать (больше 3 — будет урон).
- **«Змейка» по этажам**: «Маршруты → «Змейка»: этажи» → «Этажей» и «Шаг вниз». Углы выделяй на верхнем этаже. После последнего ряда этажа ставится спуск, следующий этаж идёт в обратную сторону.
- Детектор **«Этажи»** (вкладка «Паника»): упал не на столько, сколько ждали, не упал за 2 с, или точка на другом этаже без спуска («Нет пути») — паника.

Автоход (P, если в «Запуск» выбрано «Маршрут по точкам» или маршрут только что загружен или изменён) **не поворачивает камеру**: yaw и pitch весь проход остаются такими, какие поставил ты (удобно — пресетом камеры, K). К точке он идёт клавишами W/A/S/D относительно текущего yaw: направление раскладывается по осям камеры (8 направлений). Если yaw смотрит ровно вдоль рядов «змейки», ряды проходятся чистыми W/S, переходы — A/D. Спринт работает только вместе с W. Точка считается пройденной в радиусе 0.3 блока. Препятствия не обходит: если упёрся, срабатывает паника «Застрял». Работает всё то же, что для записи: все детекторы паники, цикл, лимиты кругов и времени, стоп при полном инвентаре, отсчёт, проверка точки старта, HUD («точка N/M») и O (продолжить с места остановки).

## Камера (yaw/pitch)

Отдельная вкладка меню **«Камера»**, не привязанная к макросам. Пресет — это имя, yaw, pitch и подпись культуры (до 16 пресетов).

- Значения вводятся числом вручную: кликни по полю, впиши, например, `90.0` или `12.345` (точка или запятая), Enter — принять, Esc — отменить. Yaw как в F3 (−180…180, 270 станет −90), pitch от −90 (вверх) до 90 (вниз). Неверное число подсвечивается красным.
- «Взять текущие» записывает в пресет, куда ты сейчас смотришь. «Yaw ровно по оси» округляет до 45°.
- **Применить пресет**: K (или кнопка «Применить» / ◎ в списке), J — следующий пресет, H — записать текущий взгляд в выбранный. Работает в любой момент, в том числе во время автохода. Не работает только пока запись играет с «Повторять камеру».
- Плавный поворот есть только здесь, при применении пресета: постоянная скорость (настраивается, °/с) с торможением в конце, без случайности. Можно выключить, тогда поворот мгновенный. Свой поворот не вызывает панику «Камера повернулась», а движение мыши поверх него вызывает.

## Настройки макроса (⚙)

У каждого макроса и маршрута свои настройки. Кнопка **⚙** есть у карточки текущего макроса и текущего маршрута (справа вверху) и у каждого сохранённого (левее ▶). Откроется окно «Настройки макроса»:

- для **сохранённого** макроса или маршрута файл переписывается при закрытии окна (кадры и точки не трогаются). Если он сейчас загружен, новые настройки сразу действуют;
- для **текущего макроса** (загруженного) — запись в файл при закрытии окна; для новой записи настройки сохранятся вместе с ней;
- для **текущего маршрута** правки помечают его «изменён» (Ctrl+Z в редакторе отменяет всё окно разом), в файл — кнопкой «Сохранить».

Править можно, пока ничего не играет и не пишется.

### Камера

Сам по себе ни макрос, ни автоход камеру не крутят. Можно выбрать:

- **Нет**: камера остаётся как есть.
- **Один на всё**: при старте (и в начале каждого круга) камера мгновенно встаёт в выбранный пресет.
- **По точкам / по кадрам**: «с точки N — пресет X» (для записи — с кадра N). При старте ставится пресет, действующий на этом месте, дальше камера мгновенно меняется, когда дошли до N.

После установки yaw/pitch больше не меняются. Плавности здесь нет: поворот мгновенный и детерминированный, детектор паники о нём знает. Хранится копия yaw/pitch, поэтому, если удалить пресет, сработают сохранённые значения. Пока у записи выбран пресет, «Повторять камеру» для неё не действует. Если yaw пресета не совпадает с yaw, с которым сделана запись, окно предупредит: клавиши из записи поведут в другую сторону.

### Зажим мыши

Держать кнопку мыши во время воспроизведения — вместе с тем, что жмёт сама запись или точка маршрута:

- **Кнопка**: нет / ЛКМ / ПКМ.
- **Когда**: весь проход, или **по участкам** (запись: «с тика … по тик …», номера кадров включительно, участков можно несколько), или **по точкам** (маршрут: галочка «Зажим мыши» в параметрах точки, Shift+ПКМ в редакторе; зажато на отрезке от неё до следующей).
- **Задержка старта**: сколько тиков после начала воспроизведения (после отсчёта) не зажимать, вводится числом (20 тиков = 1 с).

**Ручной зажим ЛКМ** — клавиша L: работает и без макроса, в HUD плашка «ЗАЖИМ ЛКМ». Не включается, пока открыт редактор маршрута.

Зажим всегда отпускается: стоп, паника, End, открытие любого окна (ручной зажим при этом выключается), выход из мира, открытие редактора. Пока открыто окно, ничего не зажимается.

### Случайность

Чтобы каждый проход был немного другим, а не «как робот». По умолчанию выключена — проход точно как раньше. Включается у каждого макроса и маршрута отдельно (⚙ → «Случайность»), общий выключатель — «Запуск → Случайность».

- **Маршрут**: на углах иногда держится старая клавиша («не сразу отпустил» — короткая диагональ), иногда на миг ничего не нажато; поворот иногда чуть раньше (срезая угол). Смазанный поворот не уходит от угла дальше «не дальше» (0.35 бл), чтобы не наступить на соседний ряд. Паузы в точках ± разброс, иногда заминка в начале отрезка (по умолчанию выкл), прыжок и спринт чуть позже, пауза перед стартом.
- **Спуск**: после приземления — случайная добавка к паузе, клавиша отпускается у края чуть раньше или позже.
- **Запись**: пока стоишь на месте, кадры иногда повторяются или пропускаются (паузы чуть длиннее/короче); ЛКМ/ПКМ нажимаются чуть позже; с «Повторять камеру» — плавный шум камеры (по умолчанию выкл).
- **Камера и зажим**: пресет привязки ставится с разбросом ± N° (по умолчанию точно), зажим мыши начинается чуть позже. Плавный поворот по K — «Скорость ±» во вкладке «Камера».
- **Сид**: 0 — каждый проход новый (сид в логе и в HUD-плашке «СЛУЧАЙНОСТЬ»); число — тот же проход каждый раз.

- **Круги** (v1.10): шанс «идеального» круга — ровно как маршрут/запись, без случайности, остановок и шума камеры; если выпал — с шансом серия из нескольких идеальных подряд (по умолчанию 8 %, серия 30 % по 2–4 круга). Шанс за круг **встать посреди пути** и пойти дальше (12 %, 0.5–2 с) и маленький шанс **долго протупить** (2 %, 5–25 с). На остановке отпускаются клавиши, ЛКМ/ПКМ и зажим мыши, детектор «Застрял» не срабатывает. Запись встаёт только там, где игрок и так стоял (на ходу запись сбилась бы).
- **Взгляд** (v1.10): на ходу pitch чуть «гуляет» (± 0.4°, yaw не трогается — от него зависит направление W/A/S/D), на остановке камера «оглядывается» (± 2.5°) и возвращается до начала движения.
- HUD-плашка: «СЛУЧАЙНОСТЬ · идеальный круг (+2) / стоит 3.5 с / круг N · сид».
- **Общая случайность**: вкладка «Конфиги» → «Общая случайность» и «Использовать для всех» (или «Запуск → Общая для всех») — одни настройки на все макросы и маршруты. В ⚙ — кнопки «Взять общие» / «Сделать общими».

Все случайные повороты мод сообщает детектору паники сам — паники «Камера повернулась» от них нет.

### Блокировка мыши

Клавиша **M**: мышь не поворачивает камеру (кнопки мыши, меню и инвентарь работают). Пресеты K/J/H, привязка камеры и «Повторять камеру» работают и при блокировке. Снимается сама: при панике (сразу, первым делом), End, выходе из мира; по настройке — и при обычном стопе. «Запуск → Блокировка мыши»: блокировать при старте макроса. В HUD — плашка «МЫШЬ ЗАБЛОК.». После перезапуска игры всегда разблокировано.

## Меню

Своё оформление, без текстур Minecraft. Настройки сохраняются сразу.

**v1.11 — меню разгружено, ни одна функция не удалена.** Вкладки: Паника, Запуск, Макросы, Маршруты, Камера, Визуал, Конфиги. **Простой режим** (по умолчанию) прячет тонкие настройки — пороги-веса, цвета, размеры, служебные шаги; **расширенный** показывает всё (пилюля у заголовка или «Ещё N настроек» внизу; скрытые настройки продолжают работать). Разделы сворачиваются кликом по заголовку (справа — «N/M вкл»), зависимые строки прячутся, пока выключен их переключатель. **Поиск** сверху ищет по всем вкладкам, клик по результату — переход к разделу. Объединено: «Безопасный звук» + «Мимо громкости игры» → «Вывод звука»; пары «от/до» случайности → одна строка; настройки рядов общие для «змейки» и авто-маршрута. Подробно — [docs/SETTINGS.md](docs/SETTINGS.md), раздел 3а.

- **Паника** (детекторы сгруппированы: камера и руки, телепорт и толчки, движение и маршрут, блоки/эффекты/режим, чат и игроки, подозрительность; затем звук, экран и журнал): поворот камеры, смена слота, урон, открытое окно, телепорт или поворот от сервера, блок вплотную к игроку, эффекты, застревание, сход с маршрута. У каждого свой переключатель и пороги. Раздел **«Сервер: проверки админа»** (v1.10) — то, что видно только по пакетам сервера: любой пакет телепорта (даже `/tp` на то же место и «посмотреть на»), толчок (скорость от сервера, удочка, взрыв), чат с твоим ником или словом из списка (свои сообщения не считаются), титры `/title` (надпись над хотбаром — только с ником/словом), смена режима игры / полёта / респавн / посадка на сущность, другой игрок подошёл ближе радиуса (кто был рядом на старте — не считается), игрок в Tab стал наблюдателем, вход/выход игроков (выход из Tab часто = «ваниш»), предмет в руке сменился или пропал сам. **v1.11**: «Синхронизация» — сервер поправил позицию/взгляд больше эпсилона (0.03 бл / 0.05°, паника с цифрами, меньше — только в лог); «Параметры движения» — сервер изменил скорость, прыжок, гравитацию, высоту шага, размер или скорость ходьбы/полёта больше 1 % (спринт не считается); «Препятствие впереди» — сервер поставил твёрдый блок на луче взгляда или по ходу автохода (до 4 бл; рост тыкв/арбузов/кактусов и поршни — нет); «Аномалия скорости» (маршрут по точкам) — скорость за тик разошлась с ожидаемой больше чем на 0.25 бл/т без толчка, прыжка и стены. Слот, сменённый сервером, ловит «Смена слота», событие урона (даже 0 и в поглощение) — «Урон». Урон от падения на точке-спуске паникой не считается. **v1.11 «Подозрительность»**: мелкие аномалии (пакет ниже эпсилона, лаг-откат, слабый толчок, игрок за радиусом, новая надпись над хотбаром, по желанию — слово в чате без ника) копят очки с затуханием (полураспад 60 с); сумма ≥ 10 — паника со списком причин; полоска «ПОДОЗР.» в HUD. **Журнал событий** — `config/farmmacro/logs/events-ДАТА.log` (старт/стоп, круги, флаги, очки, чат, паники), ротация по 5 МБ.
- **Конфиги** (v1.10): готовые наборы («Человек (рекомендую)», «Осторожный», «Мягкие детекторы», «Без случайности»), свои профили (сохранить / загрузить / перезаписать / удалить; все настройки, кроме пресетов камеры и клавиш), общая случайность.
- **Паника → звук и экран**: звук паники (4 встроенные сирены, свои `.ogg`/`.wav` или звуки Minecraft), **«Вывод звука»**: через игру (по умолчанию, безопасно) / через игру + свои файлы / через систему (мимо громкости игры), громкость, тон, число повторов, красный экран, журнал событий, кнопка «Проверить панику». Свои файлы звучат только не в безопасном режиме, иначе вместо них встроенная сирена.
- **Запуск**: что играет клавиша запуска (запись или маршрут), цикл и число кругов, лимит времени, стоп при полном инвентаре, сигнал по окончании, обратный отсчёт, точка старта, повтор камеры, общий выключатель случайности, блокировка мыши, статистика сессии.
- **Визуал**: цвета выбираются из палитры, в которой есть чёрный и тёмно-серый: лента, точки, номера, маяки старта и остановки, стрелки, превью «змейки», шляпа. **HUD**: панель статуса, навигатор (не пропадает у цели: «✔ На месте»), стрелка у прицела, полоска подозрительности, цвет и фон. **Маршрут макроса** в мире: светящаяся лента по записи или по точкам маршрута (цвет, непрозрачность и «свечение» настраиваются; номера точек над ними) (впереди ярко, пройдено серым, запись — красным), зелёный старт, красная точка остановки, текущая позиция, стрелки направления, участки ЛКМ/ПКМ и точки прыжка/приседания. Настройки: когда показывать, сквозь стены (нет / слегка / ярко), толщина, радиус, стрелки и их шаг, «от точки запуска» (если запускаешь не с места записи). Рисуется только рядом с игроком и в том измерении, где макрос записан или загружен. «China Hat» — полупрозрачная шляпа-конус над головой (видишь только ты). Пресеты «Фиолет → оранж» и «Голубой», стиль (градиент / однотонный / перелив), два цвета, прозрачность, радиус полей, высота, смещение, скорость, количество сегментов, показ от первого лица (по умолчанию нет, в F5 видно всегда), шляпы на всех игроках (по умолчанию нет).
- **Макросы**: текущий буфер (запустить, сохранить, очистить, ⚙ настройки), список сохранённых (⚙ настройки, ▶ загрузить и запустить, загрузить, удалить с подтверждением).
- **Маршруты**: текущий маршрут (редактор, запуск, сохранение, очистка, ⚙), подсказка по редактору, **авто-маршрут** (выделить область, повторить, шаг авто, поверхность, возврат к старту, пауза на концах рядов), общие настройки рядов («змейка» и авто), этажи «змейки», автоход и редактор, сохранённые маршруты.

- **Камера**: пресеты yaw/pitch (см. выше).

Любое число можно ввести вручную: кликни по значению, впиши (точка или запятая), Enter — принять, Esc — отменить; при ошибке под подписью появится причина («не число», «не меньше …», «нужно целое число»). Пределы широкие, например порог поворота можно поставить 0.001°. После клика по числу или списку (появится рамка) колёсико меняет значение (с Shift шаг крупнее), −/+ — тоже. Без клика колёсико просто прокручивает меню, поэтому пороги не собьются случайно. Tab и Shift+Tab переключают вкладки, колёсико над боковой панелью тоже.

## Файлы

- `config/farmmacro.json`: настройки.
- `config/farmmacro_macros/*.json`: сохранённые макросы (версия 5: настройки макроса в `settings` — камера, зажим мыши, случайность `human`; версии 1–4 читаются, привязка камеры из версии 3 переносится сама).
- `config/farmmacro_routes/*.json`: маршруты по точкам (версия 5: имя, мир, измерение, точки с параметрами, смещением в блоке `ox`/`oz` и спуском `drop`/`dropDir`/`landPauseTicks`/`airHold`/`dropDepth`, `settings`; версии 1–4 читаются (смещение 0, без спусков), привязка камеры из версии 2 переносится сама, старое поле pitch игнорируется).
- `config/farmmacro/configs/*.json`: профили настроек (вкладка «Конфиги»; формат как `farmmacro.json`).
- `config/farmmacro/sounds/`: свои звуки паники (`.ogg` или `.wav`). Старый `config/farmmacro/panic.wav` переносится сюда сам.

## Сборка

```
./gradlew build        # JDK 25; готовый jar в build/libs/
./gradlew soundStress  # проверка декодера звуков вне игры (1000 декодов каждого звука)
./gradlew routeStress  # упрощение маршрута на 70 000 кадров, «змейка», симуляция автохода, этажи и спуск, случайность
```

Встроенные звуки генерирует `tools/gen_panic_sounds.py` (нужны numpy и ffmpeg с libvorbis).
