# Kaelix 2.0.1

Клиентский Fabric-мод для Minecraft **26.1.2**, Java **25**, Fabric Loader **0.19.5**, Fabric API **0.155.3+26.1.2**.

## Главное в релизе
- **Hunting сохранён:** ручной Aim, ближайший живой Mob без фильтра имени либо каталог/группы, распознавание реальных типов лягушек/аксолотлей/рыб, отдельное настраиваемое упреждение.
- **Выбор наведения — список с поиском**, а не перелистывание стрелками. В Combat нажми «Управление боем», «Цель наведения», «Режим клавиши» или «Группа»: выбери строку мышью либо ↑/↓ + Enter. Колёсико прокручивает список, Esc/Назад отменяют без изменения значения. Список целей включает Hunting, Slayer-боссов/формы/мини-боссов, Dungeon-боссов/мини-боссов, каталог и своё имя.
- **Помощь по деревьям удалена полностью:** режимы, настройки, сканирование блоков, Sweep-разбор и его обработчик сообщений. Старые значения выбора `foraging:*` при загрузке заменяются на `hunting:nearby`, не включая Aim автоматически. Устаревшие поля конфигурации игнорируются и не записываются вновь.
- Итоговая версия **2.0.1**, без alpha-суффикса. По запросу пользователя в этой итерации выполняется только компиляция/упаковка (`assemble -x checkRemovedFiles`), без Minecraft, тестов, quickCheck и стресс-проверок. Релизный номер не означает новую игровую проверку.

## Сохранённые возможности
Маршруты по точкам и «Начать с места», дополнительная запись действий, общий Kaelix Motion/камера, ручной Aim на Slayer/Dungeon/Hunting, автоматический Combat/Zealots с отдельными опциями, AutoFish, HUD/инвентарь/XP/питомец, Freecam/Freelook/PiP, бинды в GUI, конфиги, оформление и ограниченные остановки при событиях.
Удалённые ранее Pests/Visitors/Bazaar/Loadouts/Experiments/Sessions/автореконнект не возвращаются.

## Ручной Aim
Combat → Управление боем → Ручной Aim / Мобы. Разреши наведение, назначь общую клавишу Aim в разделе Клавиши, выбери Hold или Toggle и цель из списка. Ты сам ходишь, рубишь обычными средствами игры, атакуешь и стреляешь; мод только поворачивает камеру. Меню/потеря фокуса/смерть/смена мира/Freecam тихо отпускают наведение. В изолированном ручном режиме нет паники на чат, телепорт или смену предмета; реально работающие автоматические модули сохраняют собственные проверки.

Hunting: ближайший режим допускает обычных животных тоже; игроки/стойки/Display не цели. Действуют дальность/FOV/видимость, захваченная живая цель удерживается до потери. Скрытые декоративные модели без видимого живого Mob-тела могут пропускаться. Упреждение для групп и известных Hunting-имён: лук/арбалет/Glacial Scythe по умолчанию, другие предметы — отдельный opt-in.40бл/с — настраиваемая оценка, без полной гравитации/сопротивления/водной баллистики. Лассо/сеть/REEL вручную. Уязвимость босса, его владелец, настоящий Livid и фазы не определяются.

## Установка
Удали старый Kaelix JAR из `mods`, установи `kaelix-2.0.1.jar` и соответствующие Fabric Loader/API. Сохрани резервную копию config и маршрутов. Старые пути mod id/package/config остаются `farmmacro`/`com.farmmacro`/`config/farmmacro`.

ZIP `kaelix-2.0.1-github-files.zip` — полный соответствующий проект, не патч; содержит `SOURCE-FILES.txt`, `REMOVED-FILES.txt`, релизный JAR и SHA256. При замене проекта обязательно удали файлы из `REMOVED-FILES.txt`: веб-загрузка GitHub сама их не удаляет. Не загружай кеши, пользовательский config, SDK или `.git`.

## Сопровождение
Сначала `AGENTS.md`, затем `UPDATING.md` и актуальная запись `CONTEXT.md`. Java25; обычная сборка для будущей разработки — `bash gradlew --no-daemon build`. В этой релизной итерации по просьбе пользователя тесты и проверки не запускались. См. `RELEASE-2.0.1.md`.
