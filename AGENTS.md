# AGENTS.md

Сначала прочитай `UPDATING.md` (актуальная передача проекта и порт Minecraft/Fabric), затем `CONTEXT.md` перед правкой. Там правила (раздел 0), границы (раздел 1), архитектура и особенности API Minecraft 26.1.2.

Коротко:
- Сборка: `./gradlew build` (JDK 25).
- После каждого изменения — запись в `CONTEXT.md` → «Журнал» (что / зачем / как проверено / что осталось) и обновление README при изменениях для игрока.
- Текущая паника alpha.5+: без B-плашки/обязательного подтверждения и без автоматических автоответов/поворотов/возобновления. Мягкие Farm-события — короткая ограниченная задержка, Combat/критические — сразу. Не возвращать устаревшее поведение из старого журнала.
- По запросу пользователя Minecraft/runClient/runServer и тяжёлые tests не запускать; только build и bounded quickCheck. Каждый выпуск: JAR + полный соответствующий source ZIP.
- Скилл для ИИ-агентов: `.agents/skills/minecraft-mod-dev/SKILL.md` (копия для Claude — `.claude/skills/minecraft-mod-dev/SKILL.md`). Правила FarmMacro в его начале важнее общих примеров (1.21.x, NeoForge, блоки/datagen).
