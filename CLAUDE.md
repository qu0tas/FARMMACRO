# CLAUDE.md

Прочитай `CONTEXT.md` целиком перед любой правкой. Там правила (раздел 0), границы (раздел 1), архитектура и особенности API Minecraft 26.1.2.

Коротко:
- Сборка: `./gradlew build` (JDK 25).
- После каждого изменения — запись в `CONTEXT.md` → «Журнал» (что / зачем / как проверено / что осталось) и обновление README при изменениях для игрока.
- Паника = стоп + экран + звук; по желанию игрока — человеческая реакция (выкл по умолчанию). Реакция: оглядеться и одна фраза в чат; любой ввод игрока её сразу прекращает. Вывод окна игры вперёд остаётся отдельной настройкой (v1.16.3); других автоматических действий паника не делает.
- Скилл для ИИ-агентов: `.agents/skills/minecraft-mod-dev/SKILL.md` (копия для Claude — `.claude/skills/minecraft-mod-dev/SKILL.md`). Правила FarmMacro в его начале важнее общих примеров (1.21.x, NeoForge, блоки/datagen).
