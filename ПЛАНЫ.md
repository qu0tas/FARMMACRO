# Планы SkyBlock

Идеи для следующих версий. **Автофункции ниже ещё не реализованы; в 1.18.0-dev подготовлена общая навигация**, не обещание сроков. Серверные механики и правила проверить перед разработкой; опасные действия только с явными настройками игрока и безопасной остановкой.

| Функция | Что планируется |
|---|---|
| Вредители | Обнаружение появления и количества, уведомление; отдельно — маршрут к вредителю, обработка и возврат к точке фарма. |
| Визитёры | Очередь и требования посетителей Garden, уведомления и расчёт стоимости; автоматические покупки/сдача только с лимитами и подтверждениями. |
| Компостер | Отслеживание топлива, органики и заполнения; подсказки, затем опциональное пополнение и сбор. |
| Booster Cookie | Оставшееся время эффекта, предупреждение до окончания; использование из инвентаря по явному разрешению. |
| God Potion | Контроль времени и недостающих эффектов, уведомление или безопасная остановка перед окончанием. |
| Репеллент | Статус и время действия; уведомление, опциональная повторная активация при наличии предмета. |
| Sprayonator | Учёт обработанных участков, выбранного материала и срока эффекта; план обновления без случайной траты ресурсов. |
| Смена питомцев | Проверка активного питомца и пресеты под культуры/соревнования; возврат прежнего питомца при завершении. |
| Гардероб | Пресеты комплектов, проверка текущей брони; переключение в безопасной остановке и восстановление. |
| Автопродажа | Белый/чёрный список предметов, защита редкого дропа и инструментов; способы продажи и лимиты отдельно. |
| Jacob-помощник | Напоминание о старте, культура и прогресс медали, пресет фермы; текущая остановка по лимиту Jacob остаётся отдельной. |
| Авто-постройка фермы | Сначала план/превью блоков и список ресурсов, затем отдельный разрешаемый режим строительства с проверкой границ, материалов и препятствий. |

## Общие требования
- Тестируемые чистые state machine в `src/stress`; события сервера сверяем в игре.
- Не отключать все детекторы ради одного ожидаемого действия. Разрешения узкие и одноразовые, со сроком и отменой по стопу.
- Расход ресурсов, команды, покупки и изменения мира явно включаются игроком.
- Не копировать код FarmHelper или других проектов с несовместимой лицензией.


## 5. Вредители — этапы и готовность

### А. Общий подход — сделано в 1.18.0-dev
Согласованный наземный контроллер движения/камеры, локальный проверяемый обход, остановка при смене состояния, API перемещения цели и выключаемая диагностика. Это используется авто-возвратом и может быть переиспользовано охотой, без копирования навигации в отдельный модуль.

### Б. Обнаружение — следующий этап
Сначала подтвердить реальные сигналы Garden: системные сообщения/scoreboard, количество/участок, доступные клиенту сущности. Не считать любой armor stand или сообщение игрока пестом. Хранить UUID цели, срок актуальности и причину потери. Проверять диапазон, мир и доступность. Сначала режим уведомления/подсветки без автоматической охоты.

### В. Подход и инструмент
Состояния: сохранить точку возврата → выбрать подтверждённую цель → построить подход → довести камеру → применить разрешённый предмет → подтвердить результат → следующая цель/возврат. Отдельно проверить Vacuum и Lasso: item id, дальность, line-of-sight, удержание/клик, кулдаун. Эти механики не угадывать по анимации видео. Управление камерой для наведения имеет приоритет над навигацией.

### Г. Защита от циклов и восстановление
Таймаут цели и охоты, предел обновлений/перепланов, недоступная/исчезнувшая цель, отсутствие инструмента, полный инвентарь, смерть, неожиданный телепорт и отключение. Останавливать/возвращаться с понятной причиной. Другие детекторы работают; автоматические команды/расходы — только явно разрешённые игроком.

### Д. Критерии полноценной готовности
Проверка в реальном Garden на Minecraft 26.1.2: несколько типов/высот целей, движущийся пест, препятствие на пути, потеря/смерть цели, отсутствие предмета, возврат к сохранённому фарму и длительный прогон. Навигационные синтетические и локальные vanilla-тесты не заменяют этот этап. Автоохота до него не отмечается готовой.
