# Kaelix 2.0.0

Стабильный релиз на основе alpha.34, принятой пользователем после проверки в игре. Новые механики при переводе в 2.0.0 не добавлялись; Java-код, настройки и игровые ресурсы сохранены без изменений, кроме текста «Что нового».

## Главное
- Маршруты по точкам — основной рабочий процесс. Запуск у точки, копирование со сдвигом и зеркалированием; запись действий остаётся дополнительной функцией.
- Kaelix Motion — общие настройки движения и камеры, Kaelix / адаптированный Aether backend. Автовозврат выключен по умолчанию. Combat-профили не перезаписывают глобальную камеру.
- Combat / Hunting: профили целей и отдельные настройки аварийной остановки. Ручной режим «Только наведение / Slayer» работает по Hold или Toggle: камера следует за видимой целью, движение, атаки и лечение остаются за игроком. Скорость — в Motion; бинд — в «Клавишах».
- Ручная смена предметов хотбаром/колесом в режиме наведения сохраняет захват. Подтверждается конкретный локальный ввод, а не общий период игнорирования событий. Неожиданная серверная подмена при включённой проверке оружия остаётся причиной остановки.
- Шесть Slayer-веток: выбор боссов/форм отдельно от мини-боссов. Каталог не определяет принадлежность босса игроку или его неуязвимость.
- Freecam: «Внешний вид → Freecam / обзор и окно». WASD / Space / Shift, выход биндом или End. Включение останавливает автоматику, выход её не возобновляет; тело игрока остаётся уязвимым.
- Каталог модулей с категориями, pixel-art иконками и настройками только открытого модуля. Slate HUD, редактор позиций/масштаба, ситуационная или постоянная видимость, инвентарь 27+9 и привязанная модель игрока.
- XP навыков, включая Combat, остаток до уровня и темп при доступных данных. XP питомца — свежий снимок вручную открытого Pets, до 60 секунд; неизвестные данные не выдумываются.
- Фоновая работа запущенных задач при Alt+Tab/PiP — явная настройка Motion. Ручной Slayer-аим требует фокуса игры. Меню, смена мира и аварийные остановки по-прежнему имеют приоритет.

## Ограничения и дальнейшая работа
Приоритет мешков Tarantula остаётся экспериментальным даже в стабильном релизе мода: приблизительный визуальный центр модели, выстрел вручную, без баллистического упреждения и подтверждения своего босса. Подробности — SLAYER-CATALOG.md.

Автоэнчантинг Experimental Table НЕ входит в 2.0.0. Требования сохранены в NEXT-EXPERIMENTS.md для отдельной следующей версии.

Автопесты, гости, продажа через базар и лодауты не являются активными функциями. Сессии/автореконнект отключены; совместимые старые поля конфигурации могут сохраняться.

Автоматизация может нарушать правила сервера. Название stable не означает гарантию отсутствия ошибок, банов или обнаружения проверок персонала.

## Установка
Minecraft 26.1.2 • Java 25 • Fabric Loader 0.19.5 • Fabric API 0.155.3+26.1.2.
Сохрани копию конфигурации, убери старый Kaelix JAR и оставь в mods только kaelix-2.0.0.jar. Mod ID и папки farmmacro не менялись; миграции/сброса настроек в этом релизном шаге нет.

Пользователь сообщил, что alpha.34 работает, и одобрил стабильный релиз. Со стороны сборки выполняются только clean build и короткие quickCheck; Minecraft и тяжёлые симуляции не запускаются. Лог и описание проверки прилагаются к исходникам. Полный GPL-3.0 corresponding source, лицензии и справочные оригиналы сохранены.
