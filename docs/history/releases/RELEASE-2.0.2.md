# Kaelix 2.0.2

Minecraft **26.1.2** · Fabric Loader **0.19.5** · Fabric API **0.155.3+26.1.2** · Java **25**

Релиз-чистка: функции и поведение в игре те же, что в 2.0.1; убран мёртвый код и исправлены проблемы надёжности и сборки. Полный список — в [CHANGELOG.md](CHANGELOG.md).

## Главное
- Удалены последние заглушки Pests / Visitors / Stash → Bazaar / Loadouts / расписания / автореконнекта / «человеческой реакции». Старый конфиг загружается, их ключи игнорируются.
- Атомарная запись конфига, профилей, маршрутов и макросов.
- Ошибки миксинов пишутся в журнал (`Kaelix/Guard`), фатальные ошибки JVM не глотаются.
- Сборка: JDK 25 скачивается Gradle при необходимости; `build` включает `quickCheck`; CI собирает и stress-исходники.
- Репозиторий: JAR-ы больше не хранятся в git, история перенесена в `docs/history/`.

## Установка
1. Удалите старый Kaelix/FarmMacro JAR из `mods`.
2. Положите `kaelix-2.0.2.jar` (GitHub Releases) — только один JAR мода.
3. Настройки, маршруты и макросы (`config/farmmacro*`) переносить не нужно — они читаются как раньше.

## Обновление исходников через GitHub «Add files»
Веб-загрузка не удаляет файлы. После загрузки удалите все пути из `REMOVED-FILES.txt` (раздел 2.0.2), иначе `checkRemovedFiles` остановит сборку с понятным списком.
Проще: применить патч `git apply kaelix-2.0.2.patch` (или `git am`) в локальном клоне и сделать push.

## Проверено
`./gradlew build` (включая `checkRemovedFiles` и `quickCheck`), `./gradlew compileStressJava`, `./gradlew routeStress` — проходят. **Minecraft не запускался**: короткая игровая проверка (меню, HUD, запуск маршрута, End, паника, Aim, AutoFish) — за пользователем.

Без гарантий отсутствия банов; используйте только там, где это разрешено.
