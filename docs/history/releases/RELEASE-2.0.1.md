# Kaelix 2.0.1

Релиз для Minecraft26.1.2/Fabric/Java25.

## Изменения
- Hunting сохранён: ближайшие реальные Mob-цели, каталог, ручное наведение и собственное упреждение.
- Весь выбор режимов/целей наведения в Combat теперь открывается списком с поиском, прокруткой, кликом, ↑↓/Enter; Esc/Назад без изменения. Больше не требуется листать сотни имён стрелками.
- Удалена помощь по деревьям вместе с её настройками, сканером, Sweep-обработчиком и смешанными tree-check исходниками. Hunting-only offline исходник сохранён, но в этой итерации не запускался.
- Сохранены прежние маршруты/камера/HUD/Slayer/Dungeon/рыбалка и ручной режим без паники.
- Старые tree-цели мигрируют в Hunting nearest без включения автоматики; прочие настройки/профили/бинды не сбрасываются.

## Сборка этой итерации
Только `JAVA_HOME=<Java25> bash gradlew --no-daemon assemble -x checkRemovedFiles`.
По просьбе пользователя НЕ запускались Minecraft, runClient/runServer, тесты, quickCheck, routeStress/configSweep/soundStress и checkRemovedFiles. Только обязательная компиляция/ресурсы/JAR. Новая GUI не проверялась в игре. Номер релиза не является заявлением о полной игровой проверке.

## Файлы
`kaelix-2.0.1.jar` + полный соответствующий source ZIP; перед установкой удалить прежний JAR. GitHub-файлы выкладывает пользователь. Не забыть применить REMOVED-FILES.txt при замене исходников. Лицензии/атрибуция сохранены.

Сборка завершена: `clean assemble -x checkRemovedFiles`, BUILD SUCCESSFUL,42с/5задач. Автоматические и игровые проверки не запускались.
