# Kaelix 2.0.0-alpha.25

## Запросы и изменения
- Модель персонажа была оторвана от HUD инвентаря и не переносилась. MC26.1.2 javap подтвердил: GuiGraphicsExtractor.entity записывает абсолютные GUI/PiP границы, не использует g.pose. Теперь HudModelBounds явно преобразует локальные границы и размер по текущей матрице HUD. Применяется и в общем HUD. Отдельная плашка модели не добавлена.
- По следующему запросу пользователя удалены доступные Pests/Vacuum/лассо/ловушки и Guests/Visitors: три карточки, категория Pests, две вкладки включая глобальный поиск, Pests HUD/переключатель, пять зарегистрированных клавиш, render/discovery/monitor/tick/автозапуски.
- Большие PestHunter/Visitors контроллеры заменены неподвижными compatibility seams (active=false, status=REMOVED, start/request/tick/signal без действий), удалены3GUI builders и4Visitors worker helpers. Совместимые настройки/парсеры/исторические вспомогательные классы остаются для общих адаптеров; это не доступная охота/обслуживание. Старые разрешения sanitize выключает; вручную выставленный старый конфиг не оживляет контроллеры.
- Общая навигация/полёт/автовозврат, Combat/Zealots, Базар и лоадауты НЕ удалены. Паника при появлении другого игрока/гостя — это безопасность, а не Guests NPC automation, её не выключали.
- Старые config-данные не стираются. Если Guests до обновления оставил компакторы выключенными, восстановить вручную; записи pendingCompactors намеренно сохранены, но старой кнопки восстановления больше нет.

## Граница
Minecraft/сервер/Hypixel/GUI harness не запускались; вид модели и новые меню нужно подтвердить пользователю. Никаких живых покупок/продаж, NPC действий или выстрелов не делалось. Не stable/RC и не гарантия отсутствия багов/бана. Исторический отчёт alpha24 описывает предыдущую сборку; Pests/Visitors вalpha25 уже удалены.

## Установка/исходники
Оставить один Kaelix JAR, перезапустить игру, предварительно сохранить config/farmmacro.json и папки config/farmmacro, config/farmmacro_routes. ZIP содержит полный соответствующий GPLv3 source/build scripts/ресурсы/тесты/уведомления. Исходники распаковать в ЧИСТУЮ папку, иначе удалить старые Java-файлы из REMOVED-FILES.txt. Есть альтернативный патч ТОЛЬКО для точного alpha24: применять вместо полного копирования, не вместе. Своих настроек/секретов в ZIP нет.

Навигация/Combat/market/loadout/mixins побайтово сохранены в исходниках относительноalpha24, mixin-конфигурация и старые ассеты кромеwhatsnew неизменны. GPL/license notices присутствуют. Полный source ZIP проверяется CRC и совпадением JAR; альтернативный patch проверяется применением на точный source alpha24 и побайтовым сравнением всех текущих файлов.
