# Kaelix 2.0.0-alpha.24 — проверка сборки

## Граница
Пользователь явно разрешил тесты в последнем запросе, отменив старое ограничение. Запущены JDK25 Gradle build, routeStress и soundStress -Piterations=20. Клиент Minecraft, сервер, Hypixel, GUI harness, живые финансовые операции/пакеты/выстрелы не запускались. Офлайн-успех НЕ доказывает работоспособность на сервере, человеческий вид, защиту от проверки или отсутствие бана. Не stable/RC; Pests Alpha; K015 автокрафт/расширенные конфиги/update checker остаются открыты.

## Исправлено
- InventoryHud: пропущенный +col повторял первый предмет каждой основной строки. Проверены36 уникальных Inventory-индексов и36 уникальных player-menu индексов.
- Combat: поиск без цели не блокируется любым закрытым мобом/бюджетным хвостом; имя на высоте тела Enderman, приоритет точного Zealot; первый toggle после настройки не теряется; frame error локально останавливает с диагностикой. Живая геометрия выстрела обязательна.
- Реальный ограниченный порт Aether TrackingRotationStrategy (GPLv3): контроллер Aether/осмотр, старые Human/Precise сохранены. НЕ полный PestManager/RotationManager/полёт. Human delay/area/jitter не применяются к Aether; режим выбирается в GUI. Одноразовая миграция режима не разрешает автоматику.
- Combat overlap: немедленный стоп активных зиалотов при пересечении живых player AABB; не staff-идентификация; ручной B/новый старт. В тестах проверены default/routing, НЕ живая сущность.
- Базар: видимый отказ и проверка готовности. REMOTE/AUTO не требуют пустой руки и допускают точный SKYBLOCK header в End. NPC/HUB сохраняют пустой слот/разрешение/записанный возврат. Финансовые разрешения/allowlist/защищённые стаки/котировки/квитанции не сняты. Неизвестный обратный путь из End не выдумывается.
- FlightGuide: малый arrival intent терялся в фиксированном deadband около0,7бл; исправлен относительный порог. Подтверждение посадки остаётся отдельным FlightArrival.
- Лестницы: подтверждённый последние1,4бл подход с проверкой3x3опоры/объёма/опасностей/таймаута; сохранён соседний выход, высота верхнего схода и непрерывная наблюдаемая лестница до нижнего схода. Контакт не сбрасывается раньше полного выхода. Проверки GroundProbe общих опасностей не ослаблены.

## Офлайн-проверки — успешный полный прогон
Команда: `JAVA_HOME=/data/jdk25 PATH=/data/jdk25/bin:$PATH bash gradlew --no-daemon build routeStress soundStress -Piterations=20`.

- Реестр49детекторов: настройки/действия/миграции/троттлинг/счётчики. BigPanic/Players/Sync/Velocity: обоснованные импульсы, остановки/застревание и ложные срабатывания в модели. Это не49реальных игровых проверок.
- CorrectionWindow: число, сумма пути, время, expiry/reset, отрицательные/NaN/infinite, hard-cap12; Combat overlap routing.
- Humanizer:200сидов рядов; углы/микропаузы200сидов, отклонение≤0,33бл при допуске0,35; Gaussian/no-repeat/range проверки,20тыс.кругов,20тыс.MouseTurn.
- RouteRandom:500сидированных симуляций/65783проверки. ReturnGuided:60полей препятствий/6724проверки.
- CombatRegression:128сидированных Human+jitter планов, границы/реакция/сходимость/разнообразие; Aether20/30/60/144/360fps, joint cap/квантование; миграция/import без включения действий; логика chain-target/rear timeout. НЕТ живых мобов/попаданий/оценки незаметности.
- SaleStart: таблица всех preflight-врат, End/full hotbar REMOTE, NPC hand/HUB landing и запрет неизвестного возврата, строгие цены и default OFF/empty allowlist. НЕТ подтверждения реальных серверных меню/receipt/экономической операции.
- InventorySlots:36+36 уникальных источников/недопустимые клетки. НЕТ визуального рендера предметов.
- NavigationBoundary: близкий полётный intent0,4/0,55/0,7/1бл, лестница contact/support/body/hazards/distance/height/timeout, запрет посадки без опоры.
- PathCheck52проверки: ступени, провалы/опасности/тупик/пределы/спуски/плиты/сглаживание, толчки, лестница вверх/вниз, двери. FlyCheck13проверок: пропасть/колодец/ограничение высоты/лава, долёт+наблюдаемая посадка в упрощённой модели.
