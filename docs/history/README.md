# История проекта

Архив, перенесённый из корня репозитория в 2.0.2, чтобы корень оставался читаемым. Это **история**, а не правила:
описанные здесь версии и модули (Pests, Visitors, Stash → Bazaar, Loadouts, расписание, автореконнект,
«человеческая реакция») могут быть уже удалены.

| Папка / файл | Что внутри |
|---|---|
| `CONTEXT-JOURNAL.md` | журнал изменений из `CONTEXT.md` до 2.0.1 включительно |
| `releases/` | заметки к выпускам 1.16.3–2.0.1 (`RELEASE-*.md`, `RELEASES-*.md`) |
| `validation/` | отчёты проверок `VALIDATION-*.md` по версиям и лог `clean-build-quickCheck.log` |
| `build-logs/` | старые логи сборки |
| `retired/` | описания удалённых модулей (Visitors, Stash → Bazaar, Loadouts, Sessions) |

Актуальное: `README.md`, `CHANGELOG.md`, `RELEASE-2.1.0.md`, `UPDATING.md`, `CONTEXT.md`.
Готовые JAR больше не хранятся в git — они прикладываются к GitHub Releases.
