# K2-011 — стеш → Bazaar → Instant Sell (alpha.17)

**Реализация для перечисленных форматов; игровая приёмка НЕ пройдена.** Это не stable 2.0.0. Не запускались Minecraft/client/server, тесты/stress/симуляции/benchmarks/GUI-стенды. Проверка только исходниками/API/javap, компиляцией `bash gradlew --no-daemon jar` и содержимым архивов. Ни один пункт ниже не означает подтверждённое исполнение на живом Hypixel.

## Согласованный режим и два способа доступа

- **Только Instant Sell:** продажа в текущие buy orders, без создания sell offers. Официальная команда — `/bazaar` (также `/bz`), не `/bazar`.
- **REMOTE:** открыть `/bazaar` с Cookie Buff. Без Cookie локальный стоп.
- **HUB:** с отдельным разрешением Hub travel выполнить `/hub`, физически подойти к реальному NPC Bazaar, открыть его меню. По штатном окончании `/warp garden` или `/is`, затем подойти к исходной точке, восстановить камеру/позу/руку.
- **AUTO (по умолчанию):** сначала REMOTE, только точное серверное сообщение об отсутствии Cookie разрешает HUB. Не таймаут, не неизвестное меню и не отсутствие NPC. Сам мод не утверждает, что прочитал активный Cookie Buff из интерфейса.
- Текущий первый вариант ограничен распознанными **Garden, Private Island и Hub на настоящем домене Hypixel**. Нет переходов из произвольных Mining/Combat-островов, обхода unlock Bazaar/SkyBlock Level или выдачи полёта. Если уже в Hub — подход к NPC и возврат пешком/доступным полётом, без лишнего `/hub`.

Официальная семантика: https://wiki.hypixel.net/Bazaar ; NPC/место: https://wiki.hypixel.net/Bazaar_(NPC) и https://wiki.hypixel.net/Bazaar_Alley . NPC ориентир `-32.5, 71, -76.5` — **не номер GUI-слота**. Путь строится по миру имеющимся ReturnWalker/NavigationInput, а не ставит игрока по координатам. Не копировались/адаптировались исходники или ассеты Aether; использованы идеи и собственная инфраструктура K010.

## Включение

1. Скопируй конфиги/маршруты в резервную копию, удали старый JAR Kaelix/FarmMacro, оставь ровно один alpha.17. Minecraft 26.1.2, Fabric Loader 0.19.5, API 0.155.3+26.1.2, Java 25.
2. GUI → **Стеш / Bazaar · Alpha**. Всё новое OFF: master, авто, Hub travel, resume. Белый список **пуст**. Защита хотбара ON.
3. Впиши точные ID через `;` или добавь ID предмета из руки. Переложи товар из руки/хотбара в основной инвентарь. Пример `WHEAT;ENCHANTED_WHEAT`. Доступен конечный каталог 90 ID с точными названиями из официального items API; это не весь ассортимент Bazaar.
4. Исключения перекрывают белый список. Нужен один свободный слот хотбара для пустой сервисной руки; если /pickupstash заполнил его, перед NPC выбирается другой пустой слот, иначе стоп без использования случайного предмета.
5. Выбери способ доступа и лимиты, затем «Запуск / отмена». Новая клавиша не назначена; назначь в **Клавиши**. Всего 14 вкладок и 28 редактируемых привязок.
6. Авто по сообщению стеша — отдельный OFF. Только пока собирает активная фермерская схема; строгое уведомление, одна попытка на событие, ≥30 с между попытками. Не запускается в Combat или от произвольного текста игрока/actionbar.

### Настройка пути без Cookie (обязательна заранее)

1. Разреши Hub travel. Вручную `/hub`; дождись загрузки и, **не двигая игрока и камеру**, открой GUI и запиши «прибытие в Hub», стоя на земле.
2. Вручную `/warp garden` (или `/is` для Private Island); так же сразу запиши «прибытие домой».
3. Запуск продажи можно делать в другом месте того же исходного Garden/Island. При возвращении используется записанное прибытие, затем навигация до сохранённого на старте места.
4. Сохраняются адрес сервера, измерение, realm, координаты и yaw/pitch. После смены spawn/адреса перезапиши. Прибытие должно совпасть: расстояние ≤1.25 блока, по Y ≤0.5, камера ≤6°. Если сервер при каждом варпе сохраняет иной угол/использует другой spawn, этот строгий вариант остановится; не расширяет допуск на любое перемещение.
5. Каждый собственный переход ждёт ≤6 с, один точный position-пакет, не более одного Survival respawn и одного конечного spawn-пакета способностей/атрибутов с конечными числами. Потом нужны известный realm/чанк, неподвижность, совпадающий инвентарь и 3 стабильных тика. До подтверждения действий нет.
6. Во время этого узкого перехода лишь сравнение старого мира/предмета/окружения откладывается; pending-тревоги обрабатываются, чужие position/rotation/slot/respawn отменяют продажу. Пакеты vanilla не отменяются, способности/физика не подменяются. Нет общего «игнорировать телепорт несколько секунд».

## Что именно может быть продано

**Кнопка Sell Instantly продаёт все стаки выбранного ID, не только полученные из стеша.** Уже лежавшие у тебя разрешённые товары тоже входят. Нет безопасного серверного поля «продать только новые стаки».

Поэтому весь ID пропускается, если хотя бы один его стак:
- в исходной руке, текущей сервисной руке или в защищённом хотбаре;
- имеет нестандартное имя, UUID, чары, улучшения/неизвестные ExtraAttributes (разрешены только id/timestamp), soulbound/favorite/locked/museum в lore;
- вне 36 main/hotbar слотов (например, в offhand);
- не входит в явный allowlist/входит в исключения или превышает остаток лимита предметов.

Чужие моды могут хранить свои locks вне ItemStack — этот мод их не знает. Не считай их универсально распознаваемыми: вынеси важные вещи/ID в исключения перед включением.

Не нажимаются Sell Inventory Now, Sell Sacks Now, Create Sell Offer, Buy Anyway. Никакого выбрасывания, shift-transfer, покупки, продажи essence/sacks или слепых постоянных индексов. Все GUI-слоты ищутся по серверным предметам/именам и фактической принадлежности контейнеру.

## Конечная цепочка и подтверждения

- Каждая партия: `/pickupstash` один раз → наблюдаемое увеличение серверного инвентаря и тишина обновлений ≥400 мс **либо** точное известное «стеш пуст» → рынок.
- Рост инвентаря — наблюдение после собственного запроса, не доказательство, что каждое добавление вызвано именно им. Уменьшение/замена уже имевшейся вещи не считается успешной выдачей.
- Нет пустого main/hotbar слота: /pickupstash не повторяется; сначала продаётся уже имеющееся разрешённое. Нет прогресса/доступного товара → штатное окончание с причиной. Стеш не уничтожается. Это не возвращает глобальную панику полного инвентаря.
- Корень Bazaar: известные Search + Sell Inventory Now как **признаки** (второе не нажимается), полный серверный снимок player inventory и пустой курсор. Клик разрешённого inventory-предмета открывает продукт.
- Продукт: точный заголовок товара, один Sell Instantly, точные quantity/total/click lore. Поддержаны `Amount: Nx` или `You have: N`, `Total: N coins` или `Price: N coins`, `Click to sell now!` или `Click to sell!`. Новые/иные/неполные форматы останавливаются, не интерпретируются эвристически.
- До финансового клика проверяются количество, котировка, права/исключения и все стаки. **Один финансовый клик без повторения** при потере ответа. Котировка без поля maxPrice не является атомарной гарантией минимальной цены/выручки после налога.
- Успех требует точной системной квитанции `[Bazaar] Sold Nx Name for N coins!` **плюс** свежего серверного инвентаря, отсутствия проданного ID и неизменности остальных main/hotbar слотов. «Executing instant sell», закрытие окна и уменьшение предмета отдельно — не успех. Частичное исполнение/неизвестная квитанция/новый confirm экран → стоп, без дальнейшей продажи и без rollback.
- Минимум coins/предмет по умолчанию 0. Котировка и квитанция округляются вниз при сравнении с целым порогом. Уже исполненную сервером продажу нельзя отменить, даже если квитанция ниже порога; последующие клики прекращаются.
- Новое серверное наблюдение menu/cursor отделено от клиентского click prediction. Нельзя считать предсказанное содержимое доказательством.

## Лимиты, остановка, возврат

1–10 партий (default 3), 1–36 продаж (default 12), ≤100000 предметов (default 8192), 100 GUI-кликов, 40 участков пути на цель, 60–600 с на запуск (default 240) и меньшие лимиты этапов. Неподтверждённый этап/меню/цена, недостаточное место, недоступный Bazaar/NPC/путь, неизвестный мир → локальный стоп с причиной в GUI/чате/журнале; без зацикливания и автоматического retry.

End, ручные клавиша/кнопка/колесо/движение мыши в мире, фокус/чужое меню, паника/неожиданные серверные перемещение/камера/слот, отключение master/смена конфига/мира → отмена. Нет автоперехода домой при ошибке: остаёшься в текущем месте для ручного управления. Частичные продажи/выдача из стеша сохраняются.

Только штатное окончание → возврат. Resume исходной фермы OFF, требует того же источника и ревизии маршрута, руки, точки, камеры и прежнего режима полёта. Не стартует Combat, другую ферму или автоматику после паники. Новый HUD-показатель встроен в существующую статусную карточку; общий редизайн — K013, не здесь.

## Пользовательская приёмка — ещё не выполнена

Проверяй сначала с 1 дешёвым разрешённым ID, 1 партией, минимальным количеством, авто/resume OFF. Отдельно REMOTE и заранее записанный HUB. Проверь полный/пустой стеш, заполненный инвентарь, защищённый ID в хотбаре/offhand, неизвестное меню, отключение master, End/ввод, чужой warp, штатный возврат. Если остановилось на неизвестном lore/квитанции — пришли точный текст/скриншот. Не включай автоматические дорогие продажи до своей проверки.
