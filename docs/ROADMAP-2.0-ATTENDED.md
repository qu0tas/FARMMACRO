# Kaelix 2.0 — помощник при присутствии пользователя

## Принцип
Пользователь у ПК; автоматизация коротких рутинных участков, а не unattended/AFK-цикл. Неожиданное событие — понятный стоп/сигнал/передача управления. Паника не утверждает, что человек — staff: наблюдаются только доступные клиенту события; пропуски/ложные срабатывания возможны. Не обещаем отсутствие бана.

- [x] Основной исходный режим — маршрут по точкам. Запись остаётся дополнительной функцией: начать/остановить из меню; бинды Record/Clear убраны.

- [x] Запуск/ручное продолжение только возле своей стартовой/сохранённой точки; авто-подход к старту и StartFromAnywhere удалены. Повторная проверка позиции после отсчёта. Отказ не запускает ввод.
- [x] Возврат OFF при первом переходе и для новых установок. В дальнейшем можно явно включить возврат после схода; он не разрешает подход к старту.

- [x] Маршруты → Копия и перенос: XYZ целыми блоками, зеркала X/Z; сохранить НОВЫМ именем. Исходный файл/буфер не меняются до успешного сохранения копии. Отражаются смещения, углы камеры, направления A/D при отражённой камере, направления спуска и координаты lookBlock. Привязанные углы снимаются локальным snapshot; текст команд остаётся прежним, alternative-файлы очищаются. Без проверки нового этажа: игрок смотрит геометрию в редакторе.

## Дополнительная оговорка
Камера, рандомизация и детекторы не гарантируют «human-like» поведения или распознавания staff. Использование автоматизации может противоречить правилам сервера даже при присутствии пользователя. В этой ветке нет обещаний скрытности/защиты от бана.

alpha32: общий MotionController разрешает/применяет повороты и нажатия потребителей, TrackingCamera перенесён в Motion, общий AetherTurn и единые настройки. Записанные углы и task-specific Human/Precise не заменяются одним универсальным планировщиком. Логика целей/оружия остаётся в Combat. Background permission ON с временным владением pauseOnLostFocus; нет поддельного фокуса. Реальное поведение Freecam/Alt+Tab/PiP остаётся ручной проверкой. Искусственной задержки паники нет.

alpha33: новый отдельный ручной Combat-режим «Только наведение / Slayer», не этап нового AFK-фарма. Камера через общийMotionController, deterministic DirectAimTurn наобщейбазовойскорости; не исполняетAutoFire/Sway/Idle/Special. Названиябоссов/типсовместимость/геометрия проверяютсякороткойpureтаблицей, распознавание/liveнаводка требуютпользовательскоготеста. Старыеавтопрофили/фоновыеусловиясохранены, режимвыбираетсяявно.
