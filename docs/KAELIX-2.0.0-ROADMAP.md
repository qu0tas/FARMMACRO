# Kaelix 2.0.0 — задачи и порядок выпуска

## Статус и правила

Цель: полноценный **2.0.0 только после проверки пользователем**, не переименование текущей alpha в стабильный релиз.
База: 1.18.16-crouch-local-panic-alpha. Первая итерация: **2.0.0-alpha.1**. Текущая: **2.0.0-alpha.16**, приёмка в игре ожидается.

- `[x]` = код или документ подготовлен и проверен статически/сборкой; НЕ означает проверку в игре.
- `[ ]` = предстоит. Игровую приёмку выполняет только пользователь.
- Агент НЕ запускает Minecraft, сервер, тесты, stress, симуляции, бенчмарки и игровые/GUI-стенды. Только чтение кода/API, статическая проверка, `gradlew jar` и упаковка.
- Каждый завершённый кодовый пакет: готовый JAR + накопительный ZIP исходников для GitHub, список изменений и ограничений. Без push и без публикации стабильного релиза без согласования.
- Одна задача может занимать несколько alpha. Номер alpha не равен номеру этапа; изменение плана не делает незавершённые функции готовыми.
- Один владелец клавиш/камеры, ручной ввод имеет приоритет, End освобождает автоматику. Паника не запускает автоматический чат/возобновление.
- Существующие настройки и маршруты сохраняем; новые автоматизации выключены по умолчанию. Pests и Visitors остаются экспериментальными до приёмки.
- Сначала сравнивать имеющийся код с Aether, затем улучшать. Никаких дублирующих контроллеров и слепого переноса.
- Aether 1.3.1-r6 — GPLv3. В alpha.1–12 его исходники не копируются: изучены подходы. Прямой перенос/адаптация кода требует отдельного соблюдения GPL, сохранения notices и предоставления соответствующих исходников; нельзя просто объявить такую производную сборку только MIT.
