# K2-008 / alpha.14 — Hunting, ручная помощь, ловушки

**Код реализован; игровая приёмка НЕ пройдена.** Только исходники, API/javap, `gradlew jar` и проверка архивов. Minecraft, сервер, тесты, stress, симуляции, benchmarks и GUI-стенды не запускались. Не гарантия универсальной совместимости Hypixel или защиты от блокировок.

## Режимы и управление

Pests → Vacuum / Hunting: лассо / Ручная помощь. Режим фиксируется при запуске. Старые настройки сохраняются, старый JSON создаёт `assist` с режимом Vacuum и новыми активными opt-ins OFF.

- **Hunting:** выбранный список видов; неизвестный вид не подходит. `vacuumOthers` OFF пропускает остальных, а не убивает незаметно. Нужны подходящие хотбарные Lasso и Vacuum для общего поиска/возврата. Отсутствие лассо не включает fallback на уничтожение.
- **Ручная помощь:** останавливает ферму и отпускает движение, камеру и предметы. Сам управляешь, ловишь и убиваешь. Намеренные ручные camera/slot/held-item изменения не считаются аномалией автоматики; server forced-slot/teleport/world/GUI/panic guards сохраняются. Vacuum selection, локальное уведомление и фокус окна — отдельные OFF-переключатели.
- **Клавиши по умолчанию:** F10 старт/стоп (в manual ожидании — возврат), F8 передача в ручную паузу, F9 завершение/возврат, End отмена. Бинд trap service не назначен. Все 25 зарегистрированных биндов доступны в GUI → Клавиши, конфликты показаны; runtime-подсказки используют переназначенные клавиши.

MANUAL не двигает, не стреляет и не отправляет команды. Свежий серверный результат только показывает подсказку, не отбирает управление. Возврат по F9/F10. F8 отменяет право auto-resume. Для manual-сеанса, начатого автоматикой, продолжение возможно лишь после явного finish, свежего результата и стабильного возврата к той же сохранённой ферме. Оставшиеся песты/unknown/отмена/таймаут такого права не дают.

## Лассо: действия и доказательства

1. Точные SkyBlockIDs ABYSMAL/VINERIP/ENTANGLER/EVERSTRETCH_LASSO и lore Throw/Reel In. Проверяются выбранный slot, ID/UUID, мир, lease, фокус и pending-panic. Существующая leash до нашего начала — отказ, не перехват.
2. Подход существующим ReturnWalker/FlightGuide по загруженной геометрии. Консервативная дистанция начала4.25бл, фактический луч до4.7бл, открытая точка тела и3 выровненных тика перед одним броском. Это предел контроллера, не гарантия серверной дальности предмета.
3. ATTACH подтверждается physical leash к local player либо однозначной близкой REEL-меткой. Typed overlay принимается только для выбранного вида; безымянный глобальный actionbar не привязывается к случайной цели. Метка рядом с другой распознанной целью считается неоднозначной.
4. REEL:2 наблюдения подсказки, реальный взгляд, cooldown350мс, один клик на эпоху prompt, максимум12 слоёв. Пока prompt не исчез, повторного клика нет. После потери подтверждённой привязки — конечный отказ, не blind rethrow живого лассо.
5. Escape или отсутствие attach45тиков допускают1–4 ограниченных броска. Общий таймаут5–90с. Краткая потеря открытого тела ждёт до6тиков без использования. Исчезновение ждёт результат до35тиков.
6. Поимка: после собственного reel/attached нужны свежие **типизированное `you caught … shard` и исчезновение собственной цели**. Generic/unknown сообщение, просто деспавн или отправка клика не доказывают успех. Captures учитываются отдельно от deaths. Farm completion требует ещё раз свежих K007-данных после возврата.

### Pre-stun — рискованный opt-in

Vacuum наносит damage; универсальное гарантированное оглушение официальными источниками не установлено. По умолчанию OFF и пустой список видов. Earthworm исключён. Для короткого воздействия нужны известные HP и DPS, запас `100 + 3 × DPS × ticks/20`, близость/LOS/фактический луч. Максимум1–6тиков. Unknown/низкие HP — бросок без Vacuum. Отправка не считается доказательством stun. Серверные модификаторы и внешний урон не доказаны: включение требует твоей проверки и может повредить цель.

## Визуальные подсказки

Существующий depth-tested loaded ESP сохранён. Новые трассеры — максимум12 сущностей, общий бюджет192 точек и до24 samples на сегмент. Путь — до64 фактических точек ReturnWalker, только загруженные чанки. Цвета различают tracer и реальную навигацию. Это не hidden ESP, не отображение через стены и не доказательство маршрута к незагруженной сущности.

## Ловушки: точки, очередь и перемещение

Отдельные OFF-переключатели: master, clear, refill, auto. Ручной запуск кнопкой GUI либо назначенным биндом. Auto — только свежие Full Traps/No Bait с ID#1–3, реальный harvest включённой фермерской схемы и обычные guards/Fever/time/rewarp-window. Автоматическая очередь включает только применимые сохранённые ID. Нет данных/точек — не успех и не повод покупать предметы.

Сохрани точку ног и метку `Pest/Mouse/Vermin Trap #1–3` под прицелом: рядом, в Garden, на безопасной опоре, onGround и не flying. Проверяются plot/world/dimension и координаты метки. Перенёс ловушку — пересохрани. Очередь ближайших точек, максимум3; до32 навигационных участков. Для дальних — проверяемые flight legs и уже разрешённые K007 item/plot warps с теми же точными ack/бюджетами. Финальный подход на опору. Нет разрешения/загруженного коридора — конечный отказ. Универсальный поиск неизвестных построек/Greenhouse не обещается.

Перед открытием нужна точная загруженная метка в1бл от сохранённой, до4бл от игрока, без дублей; LOS, body ray в реальной interaction range и совпавший взгляд. Ожидание своего Trap/Pets меню1.8–2с только после конкретного запроса. Затем проверяются точные Screen/menu/container/player identity. Другое окно — стоп/обычная паника, не широкий GUI-grace. Vanilla-пакеты не отменяются.

### Выпуск

Кнопка `Release All Pests` только в серверной части меню, не player inventory. Нужны свежий Full ID либо числовое trapped-count>0. После одного клика новое server-observed count0 или свежий Tab без ID подтверждает выпуск. **Выпуск не убийство.** После сервиса — обычный Hunting/Vacuum выбранного режима либо manual help. Unknown кнопка/счётчик/закрытие без результата → стоп.

### Приманка и курсор

Точный ID: COMPOST, PLANT_MATTER, DUNG, HONEY_JAR, TASTY_CHEESE, JELLY, MOONDEW. Цель1–64. Только один подходящий стек уже имеющегося player inventory; без Bazaar/NPC/стеша/покупок. Control `Trap Bait` и числовая lore Bait/Amount/Stored обязательны. Имеющийся тип должен совпадать; неизвестный тип не заменяется.

Поднять стек → дождаться server cursor → внести разницу по1 правыми кликами, каждый раз дождаться нового server cursor → вернуть остаток в тот же пустой source slot → дождаться server slot/cursor → проверить итоговый server bait-count.

`PestMenuEvidence` хранит **копии SetSlot/Content/SetCursorItem отдельно от predicted menu**. Анимация клика или другой пакет не доказывают transfer. Нет THROW, outside-slot click, fake cursor write или blind close с предметом на курсоре. Меню без этих lore/ack/slot semantics не поддерживается: явный отказ; для нового адаптера потребуется достоверный скрин/лоре. После отмены остаток может остаться на курсоре — верни вручную, мод его не выбрасывает.

### Питомцы

Pre-Mosquito — отдельный opt-in перед выпуском. Post-selected PET — после полного сервиса. Literal `/pets`, своё ожидаемое Pets/Pets(page), точный уникальный `[Lvl N] species`, ID PET и известная summon/despawn lore. Дубли видов, отсутствие на текущей странице или unknown lore — отказ, не случайный питомец. Активность требует свежего server slot/ID/UUID (если дан) и active lore. Клик сам не успех. Покупок и глобального лоадаута нет: K009 позже.

## Пределы и завершение

- Service20–240с плюс общий deadline K007; обычный шаг<=12с, NAV в пределах service deadline.
- Open45–60тиков, release70, cursor/PET/verify60; максимум210 menu-clicks,3 точки,32 navigation legs, item-travel budget12.
- Паника, ручная отмена, чужой GUI, потеря фокуса/мира/предмета/контекста отменяют всю цепочку и право resume. Pending trap request очищается даже до активного запуска.
- Ранний возврат не считает оставшихся пестов убитыми. Возврат Garden — в тот же подтверждённый Garden/world/start, не blind `/warp` после смены мира.
