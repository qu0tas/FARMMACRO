# Песты v1 / исправления навигации — 1.18.1-pests-dev

## Статус проверки
Компиляция и упаковка JAR выполнены через `gradlew jar`. Minecraft, сервер, stress и игровые тесты **не запускались по просьбе пользователя**. Это экспериментальная версия; успешная компиляция не подтверждает работу в Garden и не гарантирует исправление каждого подъёма.

## Как запустить
1. Minecraft 26.1.2, Java 25, Fabric Loader 0.19.5+, Fabric API 0.155.3+26.1.2. Удалить предыдущий JAR Kaelix/FarmMacro из mods.
2. В Garden положить настоящий Vacuum в хотбар (любой из пяти известных вариантов).
3. Правый Shift → Визуал → Охота на пестов v1 → Разрешить охоту на пестов. По умолчанию выключено.
4. Закрыть меню. Подойти к участку, чтобы песты загрузились, и нажать F10 (клавиша меняется в управлении).
5. Если имя/health-tag не распознаны, можно явно навести прицел **на самого Bat/Silverfish**, а не только на декоративную стойку, и нажать F10. Произвольные стойки/NPC не используются как цели.
6. F10 повторно, End, ручной ввод, меню, смерть, телепорт, потеря мира или паника прекращают охоту.

## Что делает первая версия
- Проверяет адрес Hypixel и явную строку The Garden/Garden на sidebar. Если она не читается — не запускается.
- Распознаёт живые загруженные Bat/Silverfish с именем песта либо близкой именной HP-плашкой. Нет базы текстур, анализа частиц Tracker, автоматического чтения плотов или варпов.
- Выбирает Vacuum из хотбара: серверный CUSTOM_DATA/ExtraAttributes.id или известное отображаемое имя. Дальность: lore, если указан; иначе таблица 5 / 7.5 / 10 / 12.5 / 15 блоков. Не предполагает, что любой Vacuum имеет 15 блоков.
- Останавливает текущий фарм, сохраняет точку и взгляд, берёт Vacuum. Ищет безопасные наземные/воздушные позиции в радиусе инструмента через общий ReturnWalker; камера и клавиши не принадлежат двум контроллерам одновременно.
- Когда дистанция/наведение достаточны, выполняет обычный `gameMode.useItem(MAIN_HAND)` раз в четыре клиентских тика. Это повтор нормального использования Vacuum, **без ЛКМ/ломания/ПКМ по блоку**. Серверная работа удерживаемой способности требует проверки пользователем; на бумаге её нельзя считать подтверждённой.
- Ограничивает общее время, время цели, повторные подходы и число целей (до 8); останавливает/пропускает при отсутствии наблюдаемого снижения HP. Неподтверждённое исчезновение не считается поимкой. HP-смерть означает смерть цели, не доказательство начисления Pest currency именно игроку.
- По окончании возвращается к месту запуска, восстанавливает слот и взгляд. Если начал в полёте — не пытается обязательно сесть. Фарм **не запускается автоматически**: продолжение вручную O/P.
- Существующие паника/пакетные детекторы вооружены также во время охоты. Никакого глобального отключения защит ради Vacuum. Ручной ввод имеет приоритет. Время/состояние выводятся над хотбаром, полный статус виден в меню.

## Навигационные исправления
- `returnFlyAuto=true`: воздушный путь разрешён, если сервер прислал `Abilities.mayfly` или `Abilities.flying`. Survival не запрещает полёт. Ручной старый `returnFly=false` больше не перекрывает автоматическое определение. Мод **не выставляет mayfly/flying сам**; если оба false, полёт не придумывается по Cookie lore или названию режима.
- В меню возврата отображаются оба серверных флага. Включать «Возврат на маршрут» по-прежнему нужно для обычного автоматического возврата.
- Устранена логическая блокировка промежуточной наземной точки во время полёта: достижение по высоте допускается, посадка выполняется отдельной фазой. Для воздушных подходов добавлен режим завершения без посадки.
- Взгляд не переключается за верхнюю точку, пока её высота не достигнута. Выравнивание камеры не отменяет уже требуемый прыжок. Прыжок на подъём инициируется заранее при проверенном вертикальном просвете, не только после horizontalCollision.
- Новый 3D no-progress watchdog: более 80 тиков без сдвига/прогресса приводит к ограниченному перестроению, а не бесконечному стоянию с постоянно сбрасываемым stuck-window.
- Попытки двойного прыжка сбрасываются между отдельными взлётами, а не исчерпываются навсегда на всю навигацию.

## Ограничения и следующий этап
Нет дальнего поиска по плоту/частицам, распознавания всех вариантов серверных моделей, доказанного чтения Vacuum Bag, автоматического возобновления фарма, распределённой охоты/динамического обхода сущностей. Нельзя обещать AFK-надёжность, неотличимость от человека или отсутствие ограничений сервера. Сначала проверить подъём на 1 блок, лестницы/леса, взлёт в Survival, посадку, летящего песта и реальные пакеты здоровья/расход/дальность каждого инструмента.
