# Combat / Hunting: aim assist — альфа

Kaelix **1.18.3-combat-alpha**, Minecraft **26.1.2**, Fabric, Java **25**. Компиляция/упаковка только; Minecraft и тесты не запускались. Пользователь подтвердил частичную ловлю пестов в предыдущей версии, не новые правки.

## Настройка
Правый Shift → **Combat / Hunting** → выбрать группу → отметить мобов → включить **Помощь наведения**. По умолчанию выключено. Работает рядом с выбранным видимым мобом, когда игрок уже смотрит примерно в его сторону.

- Дальность 6 бл (1–15): от глаз до выбранной точки тела. **Не увеличивает дальность удара.**
- Угол 35° (5–75): отклонение от прицела, не поиск за спиной.
- Скорость 90°/с (20–240): плавное сопровождение, без snap.
- Помощь по вертикали включена: точка тела на уровне глаз, насколько позволяет hitbox; не табличка имени.
- Только при зажатой атаке по умолчанию выключено, чтобы можно было вручную пользоваться Hunting-инструментами. Для Combat можно включить.
- Фильтр локации выключен по умолчанию: sidebar может содержать только имя подзоны, не острова. При включении неизвестная подзона блокирует помощь.
- Мышь приоритетнее, после физического движения пауза 180 мс. Помощь не пытается силой возвращать взгляд.
- Прицел уже пересекает тело — центрирование не нужно, коррекция отпускается.
- End/паника выключают aim assist в runtime. Возобновление только явным включением. Фарм/песты/редактор/пресеты/Mousemat/freelook/mouselock/Ungrab/открытые окна/свёрнутая игра приоритетнее.

## Каталог
Группы Slayer: Zombie (Hub/Crypt), Spider (Spider's Den), Wolf (Ruins/Park), Enderman (End), Blaze (Crimson Isle), Vampire (Rift). Hunting: Moonglade Marsh, Torrhus Canyon, Combat/Charm (Glacite Walker/Ghost). Есть обычные Combat-мобы.

В каждой группе отдельные флажки, кнопки выбрать/убрать всех. Смена группы заменяет список. **Мобы рядом** перечисляет реально загруженные Mob; кнопку обновления можно нажать после подхода к новому мобу. Дополнительные точные имена (без [Lv] и HP) вводятся через запятую/точку с запятой.

Это расширяемый каталог, **не обещание исчерпывающего списка каждого моба/скина на сервере**. Aim-цель — живой `Mob`, не игрок, не armor stand / NPC-табличка. Server HP-name tag может дать имя ближайшему физическому мобу; сложные составные модели, player-skin NPC, item/display-only существа пока не поддержаны. Владение Slayer-боссом не определяется. В неизвестной модели функция предпочтёт не распознать цель, а не наводиться на любого игрока.

## Что не автоматизируется
Удары, передвижение, прыжки, смена слота, использование Lasso/Vacuum/Black Hole, ловля и фарм остаются ручными. Hunting-мобы ловятся разными инструментами: часть Lasso, часть Vacuum, часть после ослабления Huntaxe с Pocket Black Hole, у Tikis есть механика пробуждения. Aim assist лишь помогает навести камеру, не обходит эти условия.

## Песты и движение
Песты остаются **Альфой** в Автоматизации: F10, прежние лимиты/стопы. Исправлен логический отказ от близкого песта из-за ненужного поиска подхода; добавлены 2 секунды памяти уже подтверждённой живой идентичности и попытка повторного распознавания в 4 бл от места исчезновения. Исчезновение не объявляется поимкой. Это не гарантия исправления каждого случая потери цели.

NavigationMotion по умолчанию держит горизонт 0°, а не смотрит вверх при подъёме. `pathHeightLook` можно включить в Автоматизации. Прицел Vacuum и aim assist по-прежнему наводятся по реальной высоте моба. Скорость ходьбы обычными клавишами не аналоговая: вместо частых throttle-импульсов на поворотах — обычная ходьба, выключение sprint, ограниченная подготовка взгляда ±25° и прежние collision checks. Торможение скорости только у финальной точки, боковые клавиши с более широким гистерезисом. Это кандидат улучшения, в игре не подтверждено.
