# K2-002 — реализация завершена, alpha.8

**Реализация K2-002 завершена; игровая приёмка ожидается. Не стабильный2.0.0.** Следующий этап реализации — K2-003 целиком. K2-001 и прежняя навигация сохранены.

- ESP и захват используют один фильтр разрешённых мобов и радиус, без отдельного потолка дальней подсветки/наведения. «Все загруженные дистанции» не увеличивает дальность оружия и не загружает сущности/чанки. FOV и ожидание выстрела намеренно отличаются цветом, а не выглядят как готовая цель.
- Подсветка: оранжевый — захват, жёлтый/голубой — доступный зилот/моб, фиолетовый — ожидание после запроса выстрела, серый — вне FOV или обычная цель при приоритете Special. Запрещённые текущим фильтром не подсвечиваются; геометрия по-прежнему depth-tested, не сквозь стены.
- Одна armor-stand табличка сопоставляется только одному ближайшему совместимому реальному мобу; стабильные ID разрешают равенство. Табличка Zealot не присваивается соседнему Zombie. Подтверждённое ранее имя того же живого объекта может сохраняться, когда дальняя табличка не пришла. Владельца Special по табличке не определяем.
- Общая ScytheShotGeometry для выстрела/точки у земли: фактический взгляд, открытая часть тела, допустимая ранняя/боковая зона либо первое столкновение с верхней поверхностью рядом с хитбоксом. Расстояние взрыва считается до реального AABB, не только до центра высокого Enderman. Консервативный предел2.3бл — политика клиента, не точная серверная сфера урона; публичная wiki описывает ground explosion3бл без подтверждённой здесь дальности болта.
- Прямой открытый луч не отвергается из-за неизвестного продолжения за мобом. ShotPath допускает известное столкновение перед первым неизвестным чанком, но никогда не считает неизвестный воздух чистым. Невалидные координаты/крайне длинный DDA ограничены ресурсным guard, не настройкой дальности оружия.
- Раннее/позднее нажатие сохраняется как отдельная опция: фактическая геометрия пересматривается каждый тик, позднее окно сбрасывается при разрыве условий. Дополнительные pre-use guards для паники/фокуса/навигации/Special. FAIL клиента не переводит на следующего; PASS/успех означают только локальную отправку запроса, не подтверждённый болт/ману/урон.
- Очередь: до512 записей, стабильный номер пока запись удерживается, пауза после запроса, повторный выбор локально живых. Наблюдавшаяся смерть и исчезновение/выгрузка разделены; смерть не приписывается игроку. В статусе — ожидание/доступные повторно/неизвестные исходы. Существующий выбор соседей и короткое ожидание перед дальним разворотом сохранены.
- Special: подтверждённый title, локальный ограниченный поиск и приоритет перед обычными мобами сохранены. Открытый живой focus не меняется; после8тиков перекрытия может уступить видимому Special вместо бессмысленного закрытого подхода. Выход цели за границу поиска прекращает преследование; исчезновение не считается смертью. Ручная отмена по-прежнему локальная и без автоматического возобновления.

Настройки/профили и форматы маршрутов не изменены; новых автоматизаций нет, KeyAuth отложен, код/ассеты Aether не копировались. **Только исходники/API/javap, gradlew jar и архивы. Minecraft/сервер/тесты/stress/симуляции/GUI-стенды не запускались.** Приёмка: `docs/navigation/TARGETS-2.0-ALPHA8.md`.

## Факты и консервативные допущения

Источник механики: https://wiki.hypixel.net/Glacial_Scythe — RIGHT CLICK Ice Bolt, ground explosion3blocks и базовая75mana. Страница не доказывает точную форму взрыва/ширину болта/время полёта/предельную дальность. Код не имитирует сервер и не меняет ману/XP/физику.

- SPLASH_REACH2.3 — консервативное клиентское расстояние от точки первого столкновения с землёй до AABB моба, с открытым impact→opening лучом. Это не радиус гарантированного серверного урона. Дальность aim не равна дальности способности.
- Early .55 / area .3 inflate — прежняя ограниченная опциональная аппроксимация у тела, не измеренная ширина болта. Можно промахиваться. Полная стена/неизвестный участок до нужной точки не даёт разрешения.
- Проверка видимого тела не доказывает попадание движущимся болтом позже; server movement, mana, cooldown, plugins и ping могут отвергнуть попытку. PASS клиента — неоднозначен, нельзя ждать только consumesAction для серверной способности, но и нельзя называть его подтверждённым выстрелом. FAIL не продвигает очередь, попытка всё равно rate-limited.
- ShotPath не идёт по неизвестному воздуху: при неизвестном продолжении проверяет лишь известный prefix и возвращает только найденный BLOCK, иначе null. Прямой вход в body проверяется до extension beyond mob.4096 chunk crossings /65536 vertical resource bounds — защита от повреждённых координат, не игровой weapon-range лимит.
- Номер очереди живёт пока локальная запись удерживается (до512), не UUID-профиль навсегда. При лимите сначала убираются не ожидающие записи; eviction не событие смерти. Удаление/выгрузка/смена объекта — неизвестный исход, даже если фактически игрок убил моба. Наблюдавшаяся смерть не доказывает, что убил именно игрок.
- Name association — ближайшее совместимое реальное тело, не владение мобом игроком. Одна табличка не размножается на соседей, но при тесном скоплении/неполных данных нельзя гарантировать верное имя. Дальний Enderman без присланного/ранее подтверждённого имени не становится Zealot автоматически; отдельный unnamed opt-in по-прежнему предупреждает об этом.
- Серый outline означает FOV/приоритет Special, не «сломанный aim». Фиолетовый — запрос в очереди. Live filter/range повторно сверяются renderer, видимость остаётся snapshot до следующего scan плюс depth test, не новый ray каждый render для всех сущностей.
- Special: максимум существующих18blocks от origin, ограниченное время, никаких warps/слотов/лут-ownership inference. Открытый живой focus не перескакивает к другому только потому, что он ближе; закрытый после grace может уступить открытому. Исчезновение запускает ограниченный поиск, не победу. После timeout обычные цели разрешаются по прежней политике; после manual/panic требуется намеренное включение.

## Ручная приёмка — выполняет только пользователь

1. На безопасном участке/локации: distant loaded Zealot с именем, затем без таблички, затем ранее виденное имя; loaded-range on/off. ESP и aim должны применять один name/range filter. Unnamed option не включается сама.
2. FOV on/off, фильтр только Zealot/другие выбранные мобы: серый вне FOV, фиолетовый pending, оранжевый захват. Запрещённый моб не выдаётся за готовую цель. Один label между соседними телами, Zombie рядом со Special label.
3. Частично открытые бок/верх/низ, краткое затем полное закрытие. Сохранение lock до grace; нет выстрела через полностью закрытое тело. Подсветка не должна стать through-wall.
4. Scythe direct, side/early area и ground рядом с высоким Enderman: проверять actual view, не желаемую камеру. Другой блок/стена до точки, земля слишком далеко от body, unknown chunk before/after known impact. Не ожидать гарантированного попадания.
5. Early/late timings: луч ушёл/ручной use/cooldown/interval/menu/panic/nav/Special — окно late не должно накапливаться через перерыв. ClientFAIL — тот же target; server/no-mana PASS не притворяется подтверждённым выстрелом.
6. Цели1→2→3 после запросов, затем первая локально жива после заданной паузы — снова доступна. Не прыгать далеко/за спину, пока есть удобные соседи. Удалённая/выгруженная не называется убитой; чужая наблюдавшаяся смерть не считается твоим kill.
7. Title Special, видимый слева/сзади, несколько открытых/закрытых. Приоритет до разрешения; живой открытый focus удерживается, короткое перекрытие не запускает беготню. После grace видимый альтернативный Special может перехватить закрытый. Граница18/timeout/menu/manual/End/паника — ограниченный отказ, не вечное преследование.
8. Регрессии K2-001: human reaction/brake/overshoot/idle/disabled pitch, Hold/Toggle, профили. Профиль/бинды/навигация/Alpha-песты не сбрасываются новой версией.
