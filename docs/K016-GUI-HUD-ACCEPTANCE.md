# K2-016 · GUI / HUD · alpha.22

## Цель
Исправить замечания пользователя к alpha21 перед итоговой приёмкой. Не объявлять весь K2-015 готовым и не публиковать stable автоматически. Последняя выданная alpha21 восстановлена из накопительного архива; её код K014 и все прежние контроллеры сохранены.

## Только выбранный модуль
Все24карточки имеют явный непустой список исходных секций. При входе в карточку нет боковых14вкладок и нет перехода колёсиком/Tab к чужой вкладке. Кнопка назад возвращает к модулям. Поиск в карточке ограничен её списком; расширенный режим раскрывает только её тонкие настройки. Полные вкладки и полный поиск сохранены через отдельную кнопку главной. У навигации не показываются расписание/reconnect: теперь это отдельная карточка системы.

Карточки не запускают контроллеры и не включают разрешения; прежние действия/проверки выполняются только исходными кнопками/биндами. Ни бинды, ни хранилища профилей в этом изменении не дублируются.

## Внешний вид HUD
HUD и редактор → стеклянный стиль включён, плотность48%, зелёный акцент. Верхняя и нижняя полосы с малым вертикальным затуханием, нет навязчивого движения/дрожания. Выключение стеклянного стиля возвращает старое оформление с прежней глобальной непрозрачностью. Личные цвета и непрозрачность плашек сохранены и имеют приоритет; пользовательские изображения и иконки также сохранены. Красные аварийные цвета не заменяются зелёным. В общей плашке полосы по внешнему контуру, а не вокруг каждой строки. Для Paper оставлен светлый фон и тёмный текст.

## HUD только по делу
По умолчанию HUDcontextOnly=true:
- активная задача: текущий контроллер/сессия/навигация либо pending-паника;
- XP/питомец: работа фермы/Pests и текущий наблюдаемый SkyBlock-контекст;
- экономика: соответствующая ферма/Pests/сервис в SkyBlock;
- инвентарь: активный контроллер/навигация/сессия, плюс собственный флаг включения;
- паника, предупреждение о незавершённом восстановлении компакторов, запись/зажим/редактор/реально включённые режимы — по существующим условиям, не спрятаны новым idle-фильтром.

В обычном одиночном мире без активной работы питомец/экономика/XP не висят. F8 намеренно показывает все плашки/заглушки, иначе их нельзя редактировать. Контекстный фильтр можно выключить, если нужен постоянный разрешённый HUD. Он не останавливает и не запускает работу, не сбрасывает статистику и не влияет на аварийный экран/звук.

## Редактор без заблокированных областей
Подсказка, инструменты и каталог — три плавающих панели. Тащи каждую за заголовок; положения сохраняются и ограничиваются размером окна при открытии. Нет фиксированной верхней/нижней зоны запрета перетаскивания HUD. Когда панель перекрыла нужную плашку, отодвинь её или нажми H: всё управление редактора скрывается, все пиксели доступны для выбора HUD. H возвращает панели, Esc сохраняет и закрывает.

C перемещает выбранную плашку/общую панель в центр без сброса цветов. При скрытых панелях стрелки двигают её по1px, Shift по8px. Колесо и Ctrl+перетаскивание меняют размер. Чтобы достать плашку за экраном: выбери в каталоге, C, затем перемести/уменьши. Полная общая панель может превышать экран — уменьши общий/индивидуальный масштаб, раздели плашки или скрой ненужные.

## Инвентарь: что исправлено и как включить
Вalpha21 глаз скрытости не включал сам флаг inventoryHUD, а отключённая плашка давала только заглушку. Теперь F8 всегда строит предпросмотр из36реальных слотов, даже при выключенной функции. Выбранная по умолчанию плашка — инвентарь. «Включить инвентарь» или + в каталоге включает флаг и снимает скрытость. Включение через HUD-настройки тоже снимает скрытость.

В игре при контекстном режиме он показывается только во время активности. Чтобы проверить вручную без макроса, можно временно выключить «HUD только по делу» — это не включает автоматику. В F8 реальный инвентарь можно увидеть независимо от этого фильтра. Инвентарь не открывается и предметы не перемещаются. Модель игрока необязательна; узкая общая панель показывает только слоты.

Для предметов используется GuiGraphicsExtractor.item(stack,x,y,seed) без привязки контекста модели игрока. Стандартные item decorations показывают количество/износ. Отдельный RuntimeException/LinkageError визуального блока изолирован через Guard и журнал, а не отключает весь HUD. Уже отключённый после прежней ошибки HUD требует перезапуска игры с новым JAR. Если ошибка останется, нужен фрагмент latest.log рядом с FarmMacro/Guard (убери сервер/ник/секреты); нельзя утверждать точную причину на чужой установке без этого.
