## 2.0.1-alpha.3 — AutoFish / рыбалка (тестовая)

Minecraft 26.1.2 · Fabric · Java 25. Отдельная карточка **Все модули → Рыбалка / AutoFish** (также категория «Фермы»), собственные настройки, бинд и перемещаемая/закрепляемая плашка HUD. На основе lyn1dev/skyblock-autofisher, CC0, commit ec82aec357406d1137189936917775030d6ef56b. Не зависимость на чужой JAR.

- Автоподсечка по `!!!` у собственного поплавка; при неоднозначности с соседним поплавком не кликает.
- Перезаброс после исчезновения своего поплавка; новый заброс подтверждается появлением нового. Без слепых повторов при потере/таймауте.
- Fireveil / ПКМ выбранным предметом: точное системное сообщение одного из 52 морских существ после своей подсечки → выбор слота → ПКМ → возврат удочки; опция выключена по умолчанию. Не автоприцел и не доказательство убийства.
- Задержки подсечки/перезаброса и три шага Fireveil доступны в GUI. Сохранены исходные диапазоны56–129/390–980мс; реализация ограничена тиками~50мс, не обещает такие точные миллисекунды. Debug локальный, не серверный чат.
- `/autofisher`, `/autofisher on/off`, `/autofisher recast on/off`, `/autofisher fireveil on/off`, `/autofisher debug on/off` — клиентские команды того же контроллера.

**Запуск:** возьми удочку в основную руку; включи разрешение; назначь бинд в «Клавиши» и запусти, либо нажми «Запуск после закрытия меню» и закрой меню за15с. Первый заброс вручную в течение60с. Разрешение сохраняется, активный запуск — никогда. После меню/смерти/смены мира/паники/End нужна новая активация. Отдельное оружие Fireveil должно лежать в выбранном слоте, не в слоте удочки.

Обычный `gameMode.useItem` и локальный vanilla выбор слота; собственных исходящих пакетов, эмуляции аппаратной мыши, фоновых планировщиков и обхода правил нет. Общие существующие проверки Паники применяются и к рыбалке; при ручных поворотах возможна остановка согласно их настройкам. Потеря удочки/вмешательство, другой владелец ввода, перенос больше4блоков и длительный провал тиков отменяют очередь без автоматического восстановления слота. Фон разрешён только настройкой «Фоновая работа».

**Важно:** автоматическая рыбалка может нарушать правила Hypixel, стандартный ввод и случайные задержки не обеспечивают отсутствие бана. Обещания upstream README о «невозможности бана» не переносились. Только сборка и короткий quickCheck; Minecraft не запускался. Подсечку/конкретное расположение серверного `!!!`/Fireveil проверь в игре сам. Камеру/Combat/точные фермерские ряды не переписывали; эксперименты, Pests, Visitors, Bazaar, Loadouts остаются удалёнными/неактивными.

Установка: удалить старый JAR, оставить только `kaelix-2.0.1-alpha.3.jar`. Полный исходный проект — в ZIP; перед загрузкой поверх репозитория удалить пути из `REMOVED-FILES.txt`. Оригинальная CC0-лицензия и pinned исходники AutoFisher включены; общий Kaelix остаётся GPL-3.0-only.

### Отличия от исходника
- Нет поиска любого !!! по всему миру: только ближайший к своему реальному FishingHook в небольшом объёме. В плотной группе сопоставление эвристическое, предпочтён пропуск неоднозначной поклёвки.
- Нет бесконтрольных ScheduledFuture после off/мира/паники и raw ServerboundSetCarriedItemPacket. Один tick-state-machine и один action за тик.
- Fireveil разрешён только после собственной подсечки, не по произвольному сообщению игрока; actionbar и signed CHAT исключены. Слишком поздняя квитанция после нового заброса игнорируется.
- Файл исходника fireveil_messages.txt в src/ не используется как runtime путь. Полный список52 фактически используемых сообщений из ExampleModClient перенесён в ресурс assets/farmmacro/fishing/sea-creatures.txt.
- Опция разрешения выключена по умолчанию. Первый ручной заброс и ручной перезапуск после стопа обязательны. Команды — те же настройки, не независимый автозапуск.
- Удержаний кнопок, автодвижения, автоопределения staff или ухода в AFK нет. Наличие опции авто-перезаброса само по себе не делает использование разрешённым сервером.

### Проверить вручную
1. В отдельной сессии без другой автоматики взять удочку, разрешить, бинд, первый заброс. У своего !!! — одна подсечка.
2. Без recast — ждать ручной заброс. С recast — дождаться старого удаления/нового появления; соседнее !!! само по себе не кликает.
3. Fireveil включить осознанно с корректным слотом; одна активация после своего catch message, возврат удочки перед новым забросом.
4. End/off/меню/разрыв/смена мира/потеря предмета до delayed click: ни одного запоздавшего клика.
5. Проверить закрепление/перемещение плашки HUD и Alt-Tab только с явно разрешённой фоновой работой.
