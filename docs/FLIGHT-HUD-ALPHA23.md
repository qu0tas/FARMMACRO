# alpha23 — приёмка общего полёта и HUD

## 2.0.0-alpha.23 — общий полёт / Pests Alpha / HUD

- Общий ReturnWalker для пестов, подходов и автовозврата: раздельный взлёт и подъём, безопасное расписание Space против случайного двойного прыжка/отключения полёта. Подтверждение взлёта требует наблюдаемого воздуха, не только flying-флага на земле.
- Устойчивый спринт на длинном свободном участке: отдельные разгон/торможение/поворот, завершение спринта перед целью без повторного включения на том же участке. Vanilla double-W не включает спринт за спиной навигатора во время leased flight; ручной полёт и наземные действия не изменены.
- Камера готовит направление следующего горизонтального участка уже при взлёте. Полёт сопровождается кадровой камерой независимо от настройки естественной наземной ходьбы. Без прямого коридора на короткой Garden-перелётной точке используется существующий ограниченный A*, а не только ожидание/повышение высоты.
- Найденный путь пестов — сплошная depth-tested зелёная лента оставшихся точек. Одноразово включается для существующих конфигов; можно выключить. Автовозврат показывает собственный путь без необходимости включать отладочные лучи. Пока поиск не закончен, выдуманной линии нет.
- Устранён переход близкого, но закрытого песта в FOLLOW без запущенного навигатора: такая цель теперь получает реальный подход.
- F8: у любой отдельной плашки переключатель «Показ: всегда / по ситуации». В «Оформление» то же для выбранной плашки. Всегда не запускает модуль: неактивная функция подписана, данных не выдумывает. «Скрыть» всё равно имеет приоритет.
- Инвентарь: 27 основных +9 хотбар-слотов с уникальными координатами, отдельный проход предметов после фона, чтение vanilla player-menu с fallback к Inventory; модель имеет собственную колонку и не перекрывает предметы. Ошибка одного предмета/модели не скрывает всю сетку. Включение инвентаря закрепляет его «всегда»; уже включённый инвентарь мигрирует так один раз, выключенный не включается сам.
- Aether: прочитаны FlightGuidance, FlightMotion, FlyExecutor, ClientUtils (ref34d3b894d407fe06a5ba1e822f0616f17beccd7b). Предпочтены разделение фаз и учёт инерции, но реализация собственная. GPLv3 код/ассеты не скопированы и не адаптированы; полной замены PestManager нет.
- Только компиляция и статическая проверка исходников/API/архивов. Minecraft/сервер/тесты/stress/симуляции/GUI harness не запускались. Сборка не доказывает работу в Garden или отсутствие багов; Pests остаётся Alpha, не stable2.0.0.
- Незавершённые K015 (автокрафт/расширенные конфиги/проверка обновлений) не закрыты этим исправлением.

## Как проверить у себя

Заменить старый JAR, не ставить два. Back up config/farmmacro.json, config/farmmacro и config/farmmacro_routes.

1. В обычном мире открыть F8. Выбрать Инвентарь; при OFF нажать «Включить инвентарь», затем «Показ: всегда». H скрывает панели редактора, C ставит выбранную плашку в центр. Закрыть Esc. Проверить три ряда с известными предметами и хотбар: пустые слоты должны оставаться клетками.
2. Для любых других плашек выбрать «Показ: всегда» в F8 или «Оформление → Оформить плашку». Без активной функции допустима только честная карточка «Неактивно / нет данных». Это не включает её автоматику, сбор данных, сети, покупки или запись.
3. В Garden проверить разрешение полёта в «Навигация и полёт»; запускать при свободном объёме над головой. Песты остаются Alpha. На длинном прямом участке ожидается удержание W+спринт, перед поворотом/целью — завершение спринта и торможение. Вблизи цели спринт специально не обязателен.
4. Следить за Space: при обычном наборе высоты автоматический повторный rising edge отделяется от предыдущего на9тиков. Двойные импульсы разрешены только взлётному автомату. В полёте никогда не меняются mayfly/flying/скорость/координаты вручную.
5. Путь показывается только после успешного поиска/проверки, сплошной зелёный для пестов, голубой для автовозврата. Depth-tested: за стеной не обещан X-ray. Пустой путь при ожидании загрузки/поиске не является вымышленным маршрутом.
6. Проверить подъём, поворот, посадку, возврат к месту запуска; ручной ввод, End, паника и смена мира по-прежнему отменяют управление. Не отключать защиту ради прохождения проверки.

## Если проблема остаётся

Нужны короткое видео с HUD «Активная задача», точный шаг (взлёт/крейсер/торможение/посадка/поиск), настройки спринта и полёта, а для исчезновения инвентаря — фрагмент latest.log с hud/inventory или hud/block_inventory. Копирование/отправка логов только вручную, лог может содержать приватные данные. Показать предметы в трёх рядах обычного E-меню для сравнения. Повторные сборки не объявляют игровую приёмку успешной.
