# K2-015 · alpha.21 · часть 1

## Что изменилось
Главная Kaelix использует 23 карточки в 7 категориях, а не сразу раскрывает много настроек. Категории: все / фермы / Combat / Pests и Hunting / сервисы / внешний вид / система. Карточки — только навигация: открытие не означает разрешение или старт. Игровые и финансовые действия находятся только внутри прежних контроллеров и их исходных строк.

Внутри фильтруемых карточек те же строки и стабильные ключи секций. Раскрытие секций локальное и не переписывает пользовательский выбор в прежних вкладках. Кнопка «Все модули»/Esc возвращает назад. Боковые старые вкладки доступны в подробном экране; переход открывает целую вкладку. «Все настройки / поиск» — полный прежний поиск по значениям/подсказкам. На главной поиск ищет по названию/описанию/категории карточки, не выдаёт себя за полный поиск всех параметров.

На главной ↑/↓ выбирают карточку с подсветкой и прокруткой, Enter открывает; Tab/Shift+Tab меняют категорию. В поле поиска эти клавиши в первую очередь принадлежат полю. Все прежние28биндов редактируются в системе → клавиши, без второго набора привязок.

## F8
- ЛКМ: выбрать и перетащить; ПКМ: скрыть/показать.
- Ctrl при начале перетаскивания: размер0.5–2.0; колесо: прежний шаг0.1 с сохранением центра.
- Snap: сетка8px и края/центр. Сетка отдельно меняет только отображение. Можно отключить Snap для свободного переноса.
- «Плашки» открывает прокручиваемый список всех20элементов, включая скрытые и без данных. Выбор не включает контроллеры. +/− и ПКМ меняют скрытость; пустая плашка может также требовать включения соответствующей HUD-функции.
- Общая плашка сохраняет прежние индивидуальные места. Её дочерние строки переносятся и масштабируются вместе; их видимость отдельно. Не меняй эту схему, если нужны индивидуальные места.
- Сброс выбранной удаляет только её слот, включая личные цвета. В общей плашке геометрия сбрасывается для `all`. Сброс всех удаляет все слоты только после второго нажатия за3с; настройки разрешений/темы/контроллеров не затрагивает.
- Уменьшение окна может потребовать Compact, меньшего масштаба, скрытия или перестановки. Все20плашек не обязаны помещаться одновременно. Редактор не раскладывает их насильно, сохраняя старые позиции; заглушки могут перекрывать друг друга, для выбора используй каталог.

## Инвентарь
Новый ID `inventory`, OFF по умолчанию. Внешний вид → HUD и редактор → включить «Инвентарь HUD». Три ряда основного инвентаря и снизу9хотбар-слотов, выбранный слот выделен. Это vanilla item render/decorations, не оценка дохода и не доступ к stash/sacks/виртуальному хранилищу. Предметы не перемещаются, меню не открываются, команды не отправляются.

Отдельная панель по умолчанию снизу слева; ширина не менее244GUIpx. В узкой общей плашке сетка уменьшается, модель не рисуется при ширине<244. Модель игрока необязательная: vanilla26.1.2 извлекает render-state snapshot без изменения игровой камеры. Любые несовместимости стороннего рендера требуют пользовательской проверки; можно выключить только модель.

Автокрафт/его покупки, новые миграции и подтверждения профилей, переименование/копирование конфигов, GitHub Releases checker, RC и stable. Существующие загрузка/импорт/экспорт остаются как вalpha20; не приписывать им новые гарантии. Все согласованные дополнения остаются в K2-015. Стабильная версия — только после пользовательской приёмки.

## Совместимость и границы
Сохранены старые19ID/слоты/темы/цвета,14подробных вкладок,28биндов; новыйIDинвентаря добавлен отдельно. Новые editorSnap/editorGrid и HUDinventory flags без сетевых/финансовых полномочий. Существующий FarmMacroScreen остаётся тем же типом, не расширяем allowlist безопасности. Никаких изменений наведения/камеры/движения/выстрела/торговых проверок/паники в этой части, кроме UI-кода.

Вдохновение — присланные изображения, своя реализация/стандартные иконки Minecraft. Код и ассеты Aether/Taunahi не копировались. Отсутствие raw spoofed packets не делает запрещённую сервером автоматизацию разрешённой и не гарантирует отсутствие санкций.
