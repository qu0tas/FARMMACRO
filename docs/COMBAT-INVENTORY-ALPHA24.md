# alpha24 — Combat / осмотр / инвентарь

Сборка для пользовательской проверки, не stable. По новому разрешению пользователя агент запускает build, routeStress и офлайн-симуляции. Итог в VALIDATION-2.0.0-alpha.24.md. Minecraft/сервер/Hypixel/GUI harness не запускались; офлайн-контроллеры не доказывают игровую работу.

## Подтверждённые ошибки в исходниках

- В InventoryHud основной индекс был `9 + row*9` без `+ col`: девять ячеек каждой строки читали один предмет. Теперь `9 + row*9 + col`, то есть9..35 без повторения; хотбар0..8 остаётся отдельной строкой. Координаты рендера, количества, фон и модель сохранены. Это точная причина повторов на присланном скрине, но визуальная приёмка ещё нужна.
- Любой закрытый разрешённый моб запрещал осмотр даже без захваченной цели. Теперь закрытые тела и цели вне FOV не блокируют поиск свободного сектора. Краткое перекрытие живого захвата сохраняет прежнюю паузу до8тиков; очередь отправленных выстрелов и Special не запускают обычный осмотр. Отложенные бюджетом геометрии кандидаты не запрещают поиск сектора навсегда: их тело всё равно проверяется перед захватом/выстрелом. Поиск только камерой: он не обходит стены и не разрешает выстрел без новой геометрии.
- При смене режима клавиши через GUI первый toggle-старт мог теряться из-за повторной смены внутреннего lastMode. Configure теперь синхронизирует режим вместе с намеренным сбросом активации; удерживаемая при закрытии GUI клавиша по-прежнему не запускает мод.
- Исключение кадрового контроллера больше не выключает сохранённое разрешение Aim. Оно локально останавливает запуск, показывает уведомление, оставляет stack trace `combat/aim-frame`. Это не доказательство того, что именно исключение было причиной у пользователя.

## Распознавание зиалотов

- Таблички, расположенные внутри высоты высокого Enderman, больше не отсекаются только за расположение ниже его макушки. Привязка остаётся ближайшим совместимым реальным телом по пространству, одна табличка → одно тело.
- Подтверждённое имя Zealot/Bruiser/Special выигрывает у общей health/name строки того же тела. ArmorStand не становится целью.
- Безымянный Enderman не объявляется зиалотом автоматически. Если сервер не прислал имя, прежняя опция «Дальние цели: Enderman без имени» остаётся явным выбором пользователя; может включить обычных Endermen.
- Кнопка «Скопировать диагностику Combat» показывает причины имени/FOV/радиуса/перекрытия и режим камеры. Фокус, оружие, разрешение и клавиша по-прежнему обязательны. Не заявляем, что любая возможная причина отсутствия захвата устранена без игрового лога.

## Камера Aether — реальный, ограниченный перенос

Перенесён `TrackingRotationStrategy.step` из mizly/aether, revision34d3b894d407fe06a5ba1e822f0616f17beccd7b. Исходная формула непрерывного экспоненциального сближения и общий угловой бюджет yaw/pitch используются непосредственно в `AetherTrackingTurn`. Локальный адаптер добавляет residual-квантование чувствительности и применяет результат через существующий Entity.turn, с прежним арбитром камеры. Не пишет позицию/скорость игрока, abilities или пакеты; не пишет yRotO/xRotO.

При первом чтении alpha24 камера активного и сохранённых Combat-профилей одноразово переключается на `Aether`. Профили, фильтры, кнопки разрешений, автовыстрел и его интервалы не включаются сами. Старые `Точный` / `Человеческий` доступны в «Режим трекинга» и после миграции сохраняются без повторного принуждения. Осмотр без цели использует Aether независимо от выбранного старого режима. Настройки задержки/перелёта/области/джиттера прежнего Human не применяются к Aether. Базовая скорость, множители захвата/сопровождения/Special и плавный разброс скорости остаются.

Это НЕ весь RotationManager/PestManager и не перенос всех механик движения из Aether. Полёт, ReturnWalker и Pests остаются реализацией alpha23. Не обещаем «непалевность», обход проверок или отсутствие бана.

## Игрок встал в персонажа → немедленный стоп

Combat panic → «Combat: игрок встал в персонажа» включён по умолчанию, под отдельным главным переключателем боевой паники. Только активный Combat режима зиалотов (фильтр/профиль/подтверждённый текущий Zealot). Сравниваются фактические пересекающиеся AABB локального и другого живого не-spectator игрока из живого списка мира. Не ESP-кэш, не общий радиус, не попытка определить администратора. NPC с player-сущностью тоже может сработать: серверную роль мы не угадываем.

Проверка до действий тика, на кадре и непосредственно перед автоматическим использованием косы. Срабатывает сразу: камера, A/D и выстрелы прекращаются, Special отменяется, уведомление причины + существующий сигнал/передача управления. Нет задержки «человеческой реакции», автоматического ответа, обхода игрока или автостарта после его ухода. Прежняя политика Shift при боевой панике сохраняется до ручного ввода/B. B подтверждает передачу управления; новый Combat запускается только новой клавишей. Пока тела пересекаются, повторный запуск снова остановится. Сохранённое разрешение Aim не сбрасывается.

## Перед заменой

Оставить один Kaelix JAR, перезапустить Minecraft, сохранить резервную копию config/farmmacro.json и папок config/farmmacro, config/farmmacro_routes. Настройки не загружаются на сервер. В игру агент не заходил: подтвердить инвентарь27+9, поиск/цель, режим Aether и остановку должен пользователь. Pests остаётся Alpha, K015 autocraft/config management/update checker остаются незавершёнными.

## Дополнительные исправления после разрешения тестов

Базар: ручной запуск теперь сообщает отказ, есть отдельная read-only кнопка готовности. Для удалённого `/bazaar` не требуется пустой слот и распознаётся точный заголовок SKYBLOCK в End. Это НЕ разрешает неизвестные Hub-варпы/возвраты: без Cookie из End не изобретается обратный маршрут. Включение продажи и непустой поддержанный allowlist обязательны. NPC требует пустой слот; защищённые ID, квитанции, котировки и необратимые клики остаются под прежними ограничениями.

Полёт: фиксированный deadband поглощал небольшую команду подхода около0,7бл от цели. Теперь малый ненулевой запрос может довести до радиуса приёмки; неподвижность/инерция/опасный коридор по-прежнему обрабатываются отдельно. В симуляции используется настоящий FlightArrival, а не фиктивное «ReturnCore DONE значит приземлился».

Лестницы: GroundProbe намеренно запрещает CLIMB, поэтому последняя обычная точка в клетке лестницы блокировала подход. Теперь только последние1,4бл к подтверждённой лестнице переходят в отдельный контроллер с проверкой опоры/объёма/опасностей/таймаута. План сохраняет соседнюю платформу, заканчивает подъём до её высоты; спуск продолжается по наблюдаемым непрерывным ступеням, а не неподдержанным выходом с промежуточного блока. Короткий выход сохраняется до полного схода на платформу даже после сброса onClimbable. Не является обходом коллизии или разрешением идти над пустотой.

Старые стенды исправлены под реальные нынешние контракты: передача steeringWorld/contact, ограниченное сглаживание, отдельное завершение FlightArrival; privacy-тесты требуют маскировку обоих частей webhook, gzip-bomb действительно проверяет распаковку >2MiB. Реестр детекторов не ослаблен ради прохождения тестов. Рандомизация проверяется на сидированных сериях; не доказана похожесть на человека или защита от античита.
