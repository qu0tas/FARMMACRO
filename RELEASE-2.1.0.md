# Kaelix 2.1.0

Minecraft **26.1.2** · Fabric Loader **0.19.5** · Fabric API **0.155.3+26.1.2** · Java **25**

Большой релиз надёжности и инструментов проверки. Поведение маршрутов, Motion, Combat/Hunting, AutoFish и проверок паники **не менялось**. Полный список — в [CHANGELOG.md](CHANGELOG.md).

## Главное
- **История запусков** с монетами/ч по культурам и экспортом CSV.
- **Код маршрута** `KAELIX-ROUTE1:` (буфер обмена) и **повтор** в редакторе маршрута (Ctrl+Y / Ctrl+Shift+Z).
- **Discord**: события «паника» и «запуск завершён», повтор только при ошибке соединения.
- **Отчёт об ошибке** одним ZIP с маскировкой личных данных.
- **Диагностика**: самые медленные шаги, очередь записи файлов, применённые миксины.
- Конфиг: фоновая атомарная запись, версия схемы, миграции с резервной копией.
- Исправлено: падение отчёта диагностики (из 2.0.2), громкость/тон резервного звука паники.
- Для разработки: JUnit 6, клиентские game-тесты Fabric (настоящий Minecraft), Error Prone + NullAway, Spotless/palantir, CI с релизом по тегу.

## Установка
1. Удалите старый Kaelix/FarmMacro JAR из `mods`.
2. Положите `kaelix-2.1.0.jar` (GitHub Releases) — только один JAR мода.
3. Настройки, маршруты и макросы (`config/farmmacro*`) переносить не нужно. При первом запуске `farmmacro.json` получает `schemaVersion: 1`, старая версия сохраняется как `farmmacro.json.schema0.bak`.

## Обновление исходников
Проще всего — патч в локальном клоне: `git am kaelix-2.1.0.patch` (на `main` = `f03e5ae`) или `git am kaelix-2.1.0-from-2.0.2.patch` (поверх коммита 2.0.2). Затем `git push`.
Через GitHub «Add files» файлы не удаляются: после загрузки удалите `RELEASE-2.0.2.md` из корня (перенесён в `docs/history/releases/`), иначе `checkRemovedFiles` остановит сборку.
Свои локальные ветки перед слиянием прогоните `./gradlew spotlessApply` — весь код переформатирован (palantir-java-format), иначе будут большие конфликты.

## Релиз через GitHub Actions
`git tag v2.1.0 && git push origin v2.1.0` — `release.yml` проверит, что тег совпадает с `mod_version`, соберёт и протестирует, возьмёт раздел `[2.1.0]` из CHANGELOG.md и опубликует Release с JAR, архивом исходников и `SHA256SUMS.txt`.

## Проверено
`./gradlew clean build compileStressJava` (компиляция с Error Prone/NullAway без предупреждений, `spotlessCheck`, `checkRemovedFiles`, JUnit — все тесты, включая старые quickCheck), `routeStress`, клиентские game-тесты в настоящем Minecraft 26.1.2 под Xvfb (меню, все модули, мир, HUD, редакторы, Crop Fever, паника и сброс, миксины, диагностика; скриншоты). **Не проверялось на Hypixel**: сеть, реальный фарм, Discord-вебхук и звук (в тестовой среде нет аудиоустройства).

Без гарантий отсутствия банов; используйте только там, где это разрешено.
