## Использование

1. Заменить предыдущий JAR Kaelix в mods на `kaelix-1.16.4.jar`; не оставлять обе версии одновременно.
2. ⚙ маршрута → Рандом маршрута / Чередовать с маршрутами; локальные диапазоны — в расширенном окне точки.
3. Ctrl+R в редакторе → Зарандомить / Ещё / Сохранить копией; фиолетовая лента — вариант.
4. Маршруты → Кэш чанков — вкл/выкл, лимит 64 МБ, Очистить кэш. Путь по кэшу помечен в HUD/журнале, свежие блоки перепроверяются до движения.
5. Для сборки исходников: JDK 25, `./gradlew clean build routeStress` (Windows: gradlew.bat).

Изменения выполнены локально; в GitHub не отправлялись. В архиве исходники и PATCH-1.16.4.diff, применимый к указанному исходному commit. Если используете полный архив, patch повторно применять не нужно.
