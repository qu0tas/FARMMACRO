# Changelog

## 1.11.0 — первая стабильная версия

**Minecraft 26.1.2 · Fabric Loader ≥ 0.19.5 · Fabric API 0.155.3+26.1.2 · Java 25**

### Новое
- **Пресеты камеры под культуры.** 7 стандартных пресетов: Nether Wart / Wheat, Potato / Carrot, Melon / Pumpkin, Moonflower / Sugar Cane / Wild Rose / Sunflower, Mushroom, Cactus, Cocoa Beans. Углы с точностью 0.1°.
- **«Запуск → Старт → Культура».** При старте камера плавно поворачивается к пресету выбранной культуры (в HUD «◎ ПОВОРОТ КАМЕРЫ»), затем начинается ход. Не срабатывает, если у макроса/маршрута своя привязка камеры (⚙) или запись повторяет камеру.
- **«Камера → Сбросить к стандартным»** (с подтверждением повторным нажатием).
- **Детекторы по пакетам сервера:** синхронизация позиции/взгляда (эпсилон), параметры движения, препятствие впереди, аномалия скорости.
- **«Подозрительность»** — мелкие события копятся с полураспадом и дают панику только вместе; **журнал событий** с ротацией файлов.
- Меню разгружено: детекторы сгруппированы, режимы «Простой/Расширенный», поиск по всем вкладкам.

### Удалено
- Авто-маршрут и «змейка» (Ctrl+ЛКМ / Ctrl+Shift+ЛКМ в редакторе, разделы меню, настройки `auto*` и `snake*`). Остались маршрут по точкам и запись.

### Перенос настроек
- Старый `farmmacro.json` читается: поля `auto*`/`snake*` игнорируются и больше не сохраняются.
- Свои пресеты камеры сохраняются, стандартные дописываются один раз без дублей по имени (всего не больше 16). Пустой список → 7 стандартных.
- Если `farmmacro.json` повреждён, он копируется в `farmmacro.json.broken` перед заменой настройками по умолчанию.

### Исправлено
- Поворот к пресету культуры ждёт столько, сколько нужно при выбранной скорости (до 2 мин); если не закончился — останавливается, а не крутит камеру на ходу.
- Стоп, паника и аварийная остановка во время поворота к пресету останавливают поворот.
