# Changelog

## 1.17.1 — Загрузка в стиле Kaelix

**Только сборка, в игре не проверено.** Отдельный номер мода; целевая игра по-прежнему Minecraft 26.1.2 / Fabric / Java 25.

### Новое
- Вместо стандартного красного экрана Mojang при загрузке ресурсов — тёмно-синий экран Kaelix: фирменная анимированная «K», крупная надпись KAELIX, мягкие синие акценты и ненавязчивая сетка.
- Полоска и проценты берутся из реального `ReloadInstance`, не из таймера. Показания сглажены, не идут назад; 100% показывается после штатного завершения. Подписи стадии — декоративные подписи к диапазонам прогресса, не отдельная диагностика движка.
- Foxy в маленькой боковой анимации и два танцора Fortnite без зелёного фона. Танцоры слегка покачиваются, один наклоняется/вращается; главная область логотипа и прогресса свободна.
- На этом экране **нет звуков, музыки, скримеров и случайного запуска CROP FEVER**. Статистика существующей пасхалки Foxy не меняется.
- Плавное появление при перезагрузке ресурсов и штатный двухсекундный переход к следующему экрану.
- Поддержаны начальная загрузка клиента и последующие resource reload, включая F3+T и смену ресурспаков. Это не экран лаунчера и не замена экрана входа в мир/подключения.
- Визуал → **Экран загрузки Kaelix**: выключатель замены (вернуть Mojang), отдельный выключатель мемов и отдельный выключатель анимации. По умолчанию все включены. Отключение анимации оставляет статичные персонажи/логотип и обычный переход между экранами.
- Геометрия адаптируется к размеру окна и масштабу GUI; битмапы текста/логотипов работают до готовности Minecraft Font.

### Технически
- Миксин заменяет только `LoadingOverlay.extractRenderState`. **Vanilla tick, onFinish, проверка исключений перезагрузки и восстановление после ошибки не подменяются.**
- Ранние текстуры читаются из JAR через `ReloadableTexture/NativeImage` при штатном `LoadingOverlay.registerTextures`, не зависят от уже загруженных шрифтов/ресурспаков. После reload принадлежат TextureManager; нет загрузки файлов каждый кадр.
- Три переключателя до client-init читаются отдельно из farmmacro.json (≤1 МБ), без записи и без подмены остальных настроек; после ModConfig.load переключатели из GUI применяются к следующему reload.
- При ошибке визуального обработчика Guard отключает только замену и возвращает vanilla-экран, не перехватывая ошибку самого resource reload.
- Изменения 1.17.0 (маршруты, точки, CROP FEVER и его новое прозрачное видео) сохранены; там новая заставка ничего не запускает и не меняет.

- Прежние stress-наборы, включая 417 891 проверку FeverMotion, прошли.

## 1.17.0 — Конец маршрута, новые точки и CROP FEVER

Отдельный номер и отдельный файл `kaelix-1.17.0.jar`. Включает изменения 1.16.3 и 1.16.4.

### Конец маршрута
- В ⚙ маршрута добавлен раздел **«Конец маршрута»**: Ничего / Пройти дальше / Rewarp-команда / Пройти дальше + команда.
- «Ничего» сохраняет прежнее поведение старых маршрутов.
- Выход: ещё 3 блока по умолчанию, настройка 1–30 блоков; направление по последнему отрезку либо ±X / ±Z. Зажим мыши на выходе и ожидании приостанавливается.
- После падения открывается окно ожидаемого телепорта (8 секунд по умолчанию). Если выход не привёл к падению, маршрут не продолжает идти бесконечно: останавливается с причиной.
- Rewarp-команда по умолчанию `/warp garden`, со случайной задержкой в настраиваемом диапазоне. Отправляется один раз на событие.
- Окно открывается **один раз**, не продлевается второй причиной в режиме «выход + команда». При раннем телепорте от падения отложенная команда отменяется.
- Ожидаемые серверные повороты во время окна и первый позиционный телепорт не вызывают панику. Один связанный поворот отдельным пакетом допускается ещё до 500 мс после первого телепорта в пределах того же окна. Следующий телепорт проверяется обычно; общего отключения детекторов нет. Урон от самого запланированного падения использует прежнее узкое разрешение падения.
- Не дождался телепорта → **«Rewarp: нет телепорта»**.
- После телепорта — пауза с разбросом, затем круг с точки 1. Если старт не рядом, подключается существующий поиск пути до старта. Настройки количества кругов и ручной стоп по-прежнему учитываются.
- В редакторе выход от последней точки показан оранжевым пунктиром.

### Типы точек
В расширенном окне Shift+ПКМ:
- **Обычная** — прежняя точка.
- **Ждать N мс** — задержка с ± разбросом.
- **Ждать позицию** — после достижения точки ждать попадания в точный радиус R; таймаут с выбором «паника / продолжить».
- **ПКМ предметом** — текущий/заданный слот или id предмета (Minecraft либо SkyBlock) в хотбаре; поворот на выбранный блок и один ПКМ с кулдауном, затем возвращаются прежний взгляд и слот. Нет предмета — пропуск. Нельзя прицелиться в указанный блок за 4 секунды — безопасный пропуск без клика в случайный блок.
- **Прыжок в точке** — короткое нажатие прыжка перед продолжением.
- **Команда в чат** — одно сообщение или команда с `/`.
В простом режиме поля типов скрыты, все точки **исполняются как обычные**, сохранённые расширенные данные не стираются.

Формат маршрутов **v6**: добавлены `pointAction` и `settings.routeEnd`; старые v1–v5 и прежние v6 читаются с обычными точками и выключенным концом маршрута.

### CROP FEVER
- Детектор использует точные серверные сообщения начала/конца и титр `CROP FEVER`; обычный чат игроков не является источником.
- Дублирующее уведомление «титр + чат» не перезапускает таймер. Если сообщение конца потерялось — резервный таймер 60 секунд.
- Во время эффекта Анимация `CROP_FEVER_being` из нового видео (107 кадров / 7.13 с, прозрачный фон вместо зелёного) появляется в случайных местах экрана; часть танцоров бегает и вращается, песня зациклена до конца эффекта.
- После исчезновения танцоров — задержка 500 мс, затем по центру `CROP_FEVER_end` и соответствующий звук.
- Начальная анимация заменена новым видео пользователя, зелёный фон удалён в прозрачность; музыка и завершающий мем сохранены из CROP FEVER.zip. Материалы преобразованы в PNG-атласы с исходными длительностями кадров и OGG Vorbis. Музыка использует звуковой движок Minecraft, выключается при отключении эффекта или выходе из мира.
- Настройки в «Визуал → CROP FEVER»: выключатель, громкость, число и размер танцоров.
- Источник сообщений: https://hypixelskyblock.minecraft.wiki/w/Crop_Fever. Реальные сообщения сервера и языковые варианты ещё требуют проверки в игре.

### Оформление HUD и GUI
- В «Визуал → Свое оформление»: свои HEX-цвета всей палитры (расширенный режим), непрозрачность меню/HUD, скругление и мягкие тени.
- Отдельно настраиваются фон, цвет полоски и непрозрачность выбранной HUD-плашки, включая общую плашку. Существующие F8-перетаскивание, якоря, масштаб и скрытие сохранены.
- Основное меню и окна точки/настроек маршрута можно перетаскивать за край или заголовок; двойной клик по заголовку — вернуть в центр.
- Кастомные PNG: `config/farmmacro/ui/background.png` (меню), `hud.png` (HUD), `icons/<id>.png` (иконки). Выключатель и кнопка перезагрузки, без замены JAR.
- PNG ограничены 2 МБ и 2048×2048; чтение в фоне, регистрация/освобождение текстур на клиентском потоке; нет подходящего изображения — стандартная отрисовка.
- Кнопка сброса оформления не стирает маршруты и положения HUD.

### Камера автоматического возврата
- Взгляд на точку впереди по пути, с учётом её высоты: небольшой наклон вниз на ровном участке, вверх/вниз на подъёме/спуске.
- Расстояние упреждения настраивается (по умолчанию 2.5 блока); движение камеры через существующий алгоритм мыши с текущей сенсой, разгоном/торможением и ограниченным перелётом.
- Довертывания запускаются при меньшем отклонении, но активный поворот не перезапускается от каждого мелкого изменения.
- В конце пути возвращается точный взгляд маршрута. Камера собственно фарм-маршрута и пресеты культуры не подменяются.

## 1.16.4 — рандом маршрута и кэш чанков

Только сборка и routeStress, в игре не проверено.

- Seeded-генератор на копии идеала, режимы off/each/fixed, диапазоны в ⚙ и локальные диапазоны точек; формат маршрута v6, v1–v5 читаются.
- Смещения ≤ 0.15 бл в исходном блоке и полосе ряда, закреплённые спуски/старт, паузы до/после спуска, момент отпускания клавиши, пауза последней точки.
- Ctrl+R в редакторе: превью отдельной фиолетовой лентой, Ещё, Сохранить копией (_rnd).
- Weighted-мульти-маршруты с проверкой стартов ≤ 2 бл и world/dimension; HUD и rejoin работают с выбранным вариантом.
- Навигационный кэш по секциям в r.X.Z.bin: фоновая атомарная запись, изоляция серверов/измерений, общий лимит 64 МБ, очистка, защита от битых файлов.
- A* читает выгруженные области по кэшу, перед движением проверяет свежие блоки и перестраивается при расхождении; ближайший незагруженный чанк — ожидание до 10 с.
- Новые routeStress: 500 seeded-симуляций маршрута, fixed/weights/migration и cached-path/mismatch/detour/limit/corruption.

## 1.16.3 — картинка в картинке, окно вперёд при панике, скрытие ника, Squeaky Mousemat, реакция

В игре ещё не проверено (только сборка и проверки без игры).

### Новое
- **Картинка в картинке** («Визуал → Окно: картинка в картинке»; клавиша в «Управление → Kaelix», по умолчанию не назначена): окно игры — маленькое (480×270) в выбранном углу экрана, поверх всех окон, без рамки. Во время макроса курсор отпущен (как U) — можно работать в других программах. Ещё раз — прежние место, размер и рамка. Из полноэкранного режима сначала выходит в окно.
- **Паника → окно игры вперёд** («Паника → Экран и журнал», вкл): свёрнутое окно разворачивается, выходит из «картинки в картинке», поднимается над другими окнами и получает фокус. Если Windows не даёт забрать фокус — игра мигает в панели задач.
- **Скрытие ника** («Визуал → Скрытие ника», выкл): свой ник на экране (чат, Tab, над головой, табло, титры) → «Player», по желанию ники друзей → «Friend». Режим «Только на скриншотах паники» — ник прячется на скриншоте и в тексте/имени файла для Discord. Только отрисовка у тебя, сервер и проверки видят настоящий ник.
- **Squeaky Mousemat** (пресеты камеры, «Как ставить → Squeaky Mousemat»): мод берёт Mousemat из хотбара (или из выбранного слота), жмёт ЛКМ (Snap на Hypixel), ждёт поворот от сервера, сверяет с пресетом (допуск 0.5°) и возвращает слот. Этот поворот не вызывает панику. Нет Mousemat — обычный поворот (настраивается). В предмете должен быть сохранён тот же угол, что в пресете.
- **Человеческая реакция (тест, выкл)** («Паника → Человеческая реакция (тест)»): после стопа мод 1–3 раза плавно оглядывается и с шансом 60 % пишет одну короткую фразу в чат. Только на детекторах с «☺» в «Все детекторы». Любое твоё движение мышью или клавиша — реакция прекращается.

### Изменено
- Правило «паника — только стоп + красный экран + звук» снято: паника теперь ещё выводит окно вперёд и может изобразить реакцию. Стоп, экран и сирена — как раньше.

## 1.16.2 — лестницы и двери в возврате, фоновый поиск пути, плашка паники

В игре ещё не проверено (только сборка и проверки без игры).

### Новое
- **Возврат на маршрут: лестницы, лианы, леса.** Путь может идти вверх и вниз по лестницам, лианам (в т. ч. плакучим и вьющимся), лозам светящихся ягод и строительным лесам. Вверх — держит прыжок (как ты на лестнице), вниз — отпускает клавиши и сползает; со стены на лестницу сходит с края. Застрял на лестнице 2 с без прогресса — новый путь.
- **Возврат: двери и калитки.** Закрытая деревянная или медная дверь / калитка на пути — мод останавливается, смотрит на неё и жмёт ПКМ (до 3 раз). Не открылась (приват, редстоун) — стоп с причиной, не паника. Железные двери и люки не открывает — ищет обход. В дверь — только прямо, не по диагонали.
- **Тонкие блоки больше не «стены».** Открытые двери и люки, лестницы — для поиска пути это пластина у края клетки: через проём с открытой дверью проходит, сквозь пластину — нет.
- **Поиск пути в фоне.** A* больше не считает в тике игры: мод копирует блоки вокруг (единицы мс) и ищет путь в отдельном потоке — без подвисаний на больших полях. Пока ищет — стоит, в HUD «ВОЗВРАТ … · ищу путь…»; дверь — «открываю дверь». Не уложился в 20 с — стоп с причиной.
- **Плашка «Последняя паника»** (HUD, двигается в F8): какой детектор сработал, причина и время («12:34:56 (3 мин назад)»). Показывается 30 минут после паники — «Визуал → HUD → Последняя паника» (0 — выкл, до 24 ч). Паника сама — как раньше: стоп + красный экран + звук.
- **Превью щёчек в меню**: под «Щёчки» — лицо твоего скина крупно, с щёчками по текущим настройкам (стиль, цвет, яркость, размер, высота, второй слой, пульсация).
- **Строка настроек** («Конфиги → Строка настроек»): «Скопировать строку» — все настройки (как профиль: без пресетов камеры и клавиш) одной строкой `KAELIX1:…` в буфер; «Вставить из буфера» — применить. Пробелы и переносы из чата не мешают; чужая/обрезанная строка — понятная ошибка, настройки не трогаются.
- **«Что нового»**: после обновления мода в главном меню игры один раз открывается окно с главным из версии. Снова — «Конфиги → Что нового в v…». При первом запуске (мастер настройки) не показывается.

### Изменено
- **Файл мода теперь `kaelix-<версия>.jar`** (был `farmmacro-<версия>.jar`). При обновлении удали старый `farmmacro-*.jar` из `mods` — иначе будут два мода сразу. Внутреннее имя мода и папки `config/farmmacro*` прежние, настройки и маршруты на месте.
- Старт издалека (P / O / N / после переподключения): путь ищется уже после нажатия, поэтому сообщение теперь «дойду сам (ищу путь…)», а не число точек. Путь не нашёлся — как раньше: без «Требовать точку старта» макрос стартует с места с предупреждением, иначе стоп.

## 1.16.1 — анимешные щёчки

В игре ещё не проверено (только сборка и проверки без игры).

### Новое
- **Анимешные щёчки** («Визуал → Анимешные щёчки», по умолчанию вкл): румянец на лице твоего персонажа — видно от 3-го лица (F5), во Freelook и в инвентаре. Щёчки — часть модели: двигаются вместе с головой (поворот, наклон, присед, плавание, элитры). Видишь только ты, сервер ничего не знает.
  - Стили: «Сердечко ♥..», «Сердечко ♥///», «Штрихи ////», «Просто румянец». Сердечко — с внешней стороны каждой щеки.
  - Цвет: розовые, красные, персиковые, сиреневые. Яркость 0–100 %, «Пульсация» — румянец то сильнее, то слабее.
  - «У всех игроков» (по умолчанию выкл) — щёчки и на других (тоже видишь только ты).
  - Расширенный режим: размер 50–200 %, высота и расстояние от носа (подогнать под глаза своего скина), «Поверх второго слоя скина», кнопка «Сбросить щёчки».

### Удалено

## 1.12.0 — Freelook, Low render, продолжить с места

### Новое
- **Freelook (F6)**: вид со стороны во время фарма — мышь крутит только камеру вокруг игрока, игрок и автоход не поворачиваются, детектор поворота не срабатывает. Вкл/выкл или «держать клавишу»; выключается при панике и End.
- **Low render (F7)**: рисуется только мир рядом с игроком (радиус 12 бл, 4–64), на время режима — дальность 2 чанка; прежняя возвращается.
- **Продолжить с места (N)**: встал в любом месте дороги — автоход находит ближайший отрезок маршрута (высота учитывается, этажи не путаются) и идёт дальше; также кнопка в «Маршрутах», порог «До дороги не дальше» (3 бл).
- Плашка HUD «FREELOOK · LOW RENDER».

## 1.11.1 — гуманизация ввода

### Новое
- **Гаусс-случайность**: у паузы в точке, заминки, зазора, перекрытия, шага, микропаузы, «встать», «протупить», задержки ЛКМ/ПКМ и старта — выбор «равномерное» / «гаусс» (среднее, отклонение, минимум, максимум). Раздел «Распределения» в расширенном режиме.
- **Без повторов подряд**: одно и то же значение два раза подряд перебрасывается; круг ровно той же длины, что прошлый, удлиняется на 1–3 тика.
- **Порядок на углу по весам**: перекрытие, зазор или короткий шаг назад/вбок — с весами и общим шансом.
- **Микропауза после отрезка**: шанс постоять 0–6 тиков на точке (без паники «Застрял»).
- **Поворот камеры «как мышь»** для K и пресетов культур: шаги пикселя мыши с учётом чувствительности, разгон/торможение, перелёт до 3 %, не ровные углы.
- Сид случайности — в журнале событий (`SEED`).
- Наборы «Человек» и «Осторожный» подобраны заново на симуляции.

### Перенос настроек
- Старые настройки и маршруты читаются как раньше: распределения равномерные, порядок на углу «как раньше», микропауз нет, поворот камеры прежний.

### Исправлено
- Из исходников убраны оставшиеся файлы авто-маршрута/«змейки», из-за которых не собирался проект.

## 1.11.0 — первая стабильная версия

**Minecraft 26.1.2 · Fabric Loader ≥ 0.19.5 · Fabric API 0.155.3+26.1.2 · Java 25**

### Новое
- **Пресеты камеры под культуры.** 7 стандартных пресетов: Nether Wart / Wheat, Potato / Carrot, Melon / Pumpkin, Moonflower / Sugar Cane / Wild Rose / Sunflower, Mushroom, Cactus, Cocoa Beans. Углы с точностью 0.1°.
- **«Запуск → Старт → Культура».** При старте камера плавно поворачивается к пресету выбранной культуры (в HUD «◎ ПОВОРОТ КАМЕРЫ»), затем начинается ход. Не срабатывает, если у макроса/маршрута своя привязка камеры (⚙) или запись повторяет камеру.
- **«Камера → Сбросить к стандартным»** (с подтверждением повторным нажатием).
- **Детекторы по пакетам сервера:** синхронизация позиции/взгляда (эпсилон), параметры движения, препятствие впереди, аномалия скорости.
- **«Подозрительность»** — мелкие события копятся с полураспадом и дают панику только вместе; **журнал событий** с ротацией файлов.
- Меню разгружено: детекторы сгруппированы, режимы «Простой/Расширенный», поиск по всем вкладкам.

### Удалено
- Авто-маршрут и «змейка» (Ctrl+ЛКМ / Ctrl+Shift+ЛКМ в редакторе, разделы меню, настройки `auto*` и `snake*`). Остались маршрут по точкам и запись.

### Перенос настроек
- Старый `farmmacro.json` читается: поля `auto*`/`snake*` игнорируются и больше не сохраняются.
- Свои пресеты камеры сохраняются, стандартные дописываются один раз без дублей по имени (всего не больше 16). Пустой список → 7 стандартных.
- Если `farmmacro.json` повреждён, он копируется в `farmmacro.json.broken` перед заменой настройками по умолчанию.

### Исправлено
- Поворот к пресету культуры ждёт столько, сколько нужно при выбранной скорости (до 2 мин); если не закончился — останавливается, а не крутит камеру на ходу.
- Стоп, паника и аварийная остановка во время поворота к пресету останавливают поворот.
