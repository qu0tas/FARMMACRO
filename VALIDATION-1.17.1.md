Свет рисуется только при CORE.active(), не во время завершения; общий disable/выход используют прежний reset.
- Пульсация 108 BPM по времени события, без аудиоанализа. Включено по умолчанию, сила 55 (0–100). При чувствительности к мерцанию выключить.

## Что надо проверить в игре
1. Первый запуск клиента с пустым конфигом: нет отсутствующих текстур/чёрного экрана, загрузка завершается, появляется титульное меню; картинка Kaelix вместо Mojang.
2. Перезапуск с kaelixLoading=false: vanilla Mojang; после включения в меню следующий F3+T снова Kaelix. Флаги memes/motion из config учитываются до client-init.
3. F3+T и смена ресурспака, быстрый и медленный reload; реальные проценты, плавный вход/выход, завершение без зависания.
4. Повреждённый/несовместимый ресурспак: обычная обработка ошибки и восстановление ресурсов, не вечный branded overlay.
5. GUI 2/3/4/Auto, маленькое окно, 4:3 и ultrawide. Ресайз во время reload: элементы остаются в кадре, Font/ресурсы не вызывают раннюю ошибку.
6. LoadingMemes=false: только бренд/прогресс. LoadingMotion=false: статичные K/Foxy/танцоры, штатный fade сохраняется. Никаких звуков и скримеров на загрузке.
7. Совместимость с другими модами LoadingOverlay: при двух cancellable HEAD-внедрениях порядок может влиять; лучше не включать два заменителя одновременно. Проверить F3+T с GUI/world на фоне.
8. Регрессия функций 1.17.0: маршруты/кэш/точки, CROP FEVER-видео, музыка и end-мем. Загрузочный Foxy не должен менять shown в foxy.json.

## Граница проверки
Minecraft-клиент не запускался. Применение mixin, native/GPU и настоящие переходы загрузки не подтверждены. Эта версия заменяет только LoadingOverlay загрузки ресурсов, не лаунчер/подключение/экран генерации мира. Ошибки самого resource reload не маскируются. Медиа принадлежат правообладателям; перед публикацией проверить разрешения. Релиз/тег GitHub не публиковался.
